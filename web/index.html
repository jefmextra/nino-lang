01 / Core Architecture

Design & Engineering Foundations

Explicit memory boundaries, machine-checked mathematical contracts, and bit-reproducible compiler builds.

01 / PROOF

SMT Proof-Carrying Code

Compile-time contract and loop invariant verification via Z3 across 64-bit BitVectors, IEEE 754 floating-point, and integer theories, embedding verifiable HMAC-SHA256 and Ed25519 certificates into executables.

02 / GENERICS

Monomorphized Generics

Parametric structures and algebraic data containers specialize at compile time into deduplicated, type-safe native memory layouts with zero runtime boxing or dynamic dispatch overhead.

03 / VECTORIZER

NIR SSA & Loop Vectorizer

Linear-time expression lowering paired with SSA dead-code elimination, 64-bit constant folding, proven bounds-check elision, and affine four-lane SIMD auto-vectorization.

04 / ARENA

Scoped Arena Memory

Multi-slab bump allocation with epoch-stamped array headers, deterministic Use-After-Rollback traps, static region escape checking, and machine-verified Z3 soundness theorems.

05 / BOOTSTRAP

Deterministic Self-Hosting

Self-hosted Pratt AST compiler converging bit-for-bit across bootstrap stages on both Linux and Windows from a single portable ISO C11 seed.

06 / TARGETS

ISO C11 & Native Backends

Emits strict freestanding ISO C11, LLVM SSA IR, and direct x86_64 and AArch64 machine code for Windows and Linux without external runtime dependencies.

02 / Language Specimen

Direct Systems Syntax

Explicit contracts, deterministic region lifecycles, and clean standard library pipelines.

fn transfer_funds(sender_id: i64, amount: f64) -> bool {
    require(amount > 0.0, "Transfer amount must be strictly positive")
    require(sender_id > 0, "Invalid sender identifier")

    let updated_balance = 5000.0 - amount
    ensure(updated_balance >= 0.0, "Solvency invariant breached")

    return true
}
03 / Developer CLI

Integrated Toolchain

Compiler, formal prover, native assembler, LSP, and test runner unified in a single binary.

ninoc build / run Compilation

Compiles and executes sources via GCC strict C11, LLVM, or direct PE/ELF native code generation with optional Z3 PCC certificates.

ninoc check / lint Static Analysis

Enforces static types, arity rules, sealed taint isolation, region escape analysis, and bounded control-flow checks.

ninoc prove / witness / equiv Formal SMT

Verifies contract invariants, synthesizes counterexample tests, and checks equivalence across BitVector and Float64 models.

ninoc ast / ir / llvm / asm IR & Machine Code

Inspects linked syntax trees, NIR SSA passes with loop vectorization, fail-closed direct LLVM SSA IR subset, and x86_64 or AArch64 assembly listings.

ninoc keygen / sbom / trace Assurance

Generates Ed25519 signing keys, CycloneDX software bills of materials, and SHA-256 execution state chains.

ninoc lsp / fmt / doc IDE & Tooling

Runs the JSON-RPC language server with live Z3 diagnostics, canonical code formatting, and Markdown API generation.

ninoc bindgen / mobile FFI & Mobile

Generates zero-overhead C FFI bindings and bridges targeting Android NDK Kotlin and Apple iOS Swift.

ninoc pkg / test Packages & QA

Resolves lockfile-verified packages and runs native unit suites alongside the cross-platform E2E conformance matrix.
