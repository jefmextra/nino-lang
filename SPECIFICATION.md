## Clause 1: Scope, Normative References, Terms and Definitions, and Conformance Levels

### 1.1 Scope

This International Standard style specification defines the syntax, static semantics, operational memory model, Proof-Carrying Code (PCC) verification pipeline, standard runtime interfaces, and deterministic self-hosting bootstrap protocol for the Nino programming language (`NinoLang`), version 1.2.

This specification is grounded directly in the modular self-hosted compiler implementation (`compiler/`), the reference runtime header (`runtime/nino_runtime.h`), the bootstrap seed infrastructure (`bootstrap/`), and the standard library modules (`std/*.nino`). Wherever the compiler delegates semantics to its C11 backend or provides embedded in-memory runtime engines, this specification states those boundaries explicitly.

### 1.2 Normative References

The following documents are referenced in the text in such a way that some or all of their content constitutes requirements or contextual baselines for this specification:

- **ISO/IEC 9899:2011 (C11)**: Information technology, Programming languages, C. Defines the target lowering representation (`-std=c11`), `_Generic` selection, `<stdatomic.h>` atomics, and `_Thread_local` storage duration. Default builds allow widely supported GNU C extensions (`__auto_type`, `__typeof__`, statement expressions), whereas `--strict-c11` (`-std=c11 -pedantic-errors -DNINO_STRICT_C11=1`) emits strictly ISO-conforming C11 without GNU extensions.
- **ISO/IEC 14977:1996**: Information technology, Syntactic metalanguage, Extended BNF (used for formal grammar definitions in Clauses 2 and 3).
- **IETF RFC 2119 and RFC 8174**: Key words for use in RFCs to indicate requirement levels (`SHALL`, `SHALL NOT`, `SHOULD`, `MAY`).
- **NIST FIPS 180-4**: Secure Hash Standard (SHS), specifying the SHA-256 and SHA-512 algorithms implemented by the runtime (`sha256`, `sha512`) and used for PCC certificate seals, bootstrap convergence checks, and Ed25519 key derivation.
- **IETF RFC 8032**: Edwards-Curve Digital Signature Algorithm (EdDSA / Ed25519), implemented in pure strict ISO C11 (`ed25519_keygen`, `ed25519_keygen_seed`, `ed25519_pubkey_from_sk`, `ed25519_sign`, `ed25519_verify`) for asymmetric PCC signature generation and public-key pinned binary verification (`--verify-proof --pubkey <64-hex>`).
- **JSON-RPC 2.0 Specification** and **Language Server Protocol (LSP) Specification 3.17**: Governing the wire framing and method semantics of `ninoc lsp`.
- **SMT-LIB Standard Version 2.6**: Governing the formula syntax (`(set-logic ALL)`, `(set-logic QF_BVFP)`, `Int`, `(_ BitVec 64)`, `(Array Int Int)`, IEEE 754 `Float64` / `(_ FloatingPoint 11 53) RNE`, `(assert ...)`, `(check-sat)`) generated by `synthesize_formal_smt_ex` and consumed by Microsoft Z3.

### 1.3 Terms and Definitions

For the purposes of this specification, the following terms and definitions apply:

- **Compilation Unit**: A root `.nino` source file together with all transitively included `.nino` files expanded by `expand_all_imports`.
- **Normalized Source**: The compilation unit text after CRLF normalization, line trimming, and multi-line expression joining (`normalize_and_join_lines`).
- **Core Standard Mode**: Default compilation (`ninoc build`, `ninoc run`) without `--proof`, enforcing lexical balance, static `E0384`/`E0042` checks, C11 backend compilation, and runtime safety guards.
- **Proof-Carrying Code (PCC) Mode**: Compilation invoked with `--proof`, `-proof`, or `--pcc`, defaulting to 64-bit BitVector (`QF_BV+64bit-Overflow`), IEEE 754 `Float64` (`QF_BVFP+64bit-IEEE754` / `QF_FP+64bit-IEEE754` when floating-point types are present), or unbounded `ALL/QF_NIA+Array` (`--int-logic`), requiring Z3 `unsat` verification of synthesized contracts prior to code generation and embedding a cryptographically SHA-256, RFC 2104 HMAC-SHA256, and RFC 8032 Ed25519 sealed certificate (`_NINO_PCC_ED25519_PUB`, `_NINO_PCC_ED25519_SIG`) into the binary.
- **Scoped Linear Arena (`NinoArena`)**: A per-thread bump-pointer memory region backed by chained 4 MiB `NinoArenaSlab` segments (`data`, `cap`, `used`, `base_offset`, `prev`), a 64-level mark stack (`marks[64]`), and epoch/reset generation counters (`mark_ids[65]`, `next_mark_id`, `reset_gen`), supporting O(1) bump allocation, `arena_mark()`, scoped `arena_rollback()`, and CWE-416 Use-After-Rollback runtime traps via 48-byte `NinoArrHdr` array headers.
- **Sealed Software Binding (`nino_sealed_t`)**: A compile-time XOR-obfuscated literal combined with an OS virtual-page guarded (`VirtualAlloc`/`VirtualProtect` `PAGE_NOACCESS` and `VirtualLock` on Windows; `posix_memalign`/`mprotect` `PROT_NONE` and `mlock` on POSIX when OS limits allow) XOR-masked buffer (`cipher`, `pad`, `len`), 32-bit `0xDEADC0DE` / `0xFEEDFACE` integrity canaries, and volatile destruction (`seal_destroy`). This provides software defense-in-depth rather than hardware TEE/SGX silicon memory encryption.
- **Implementation-Defined Behavior**: Behavior that depends on the host platform, C11 compiler (`gcc` or `clang`), or operating system APIs, and is documented in this specification.
- **Hybrid & Embedded Runtime Subsystems**: Runtime modules supporting dynamic native OS/network backends (`db_postgres_*` over PostgreSQL v3 TCP wire protocol failing closed offline; `db_sqlite_*` loading system `sqlite3` or using resizable embedded SQL tables; `db_redis_*` probing live RESP-2 TCP sockets over 50ms non-blocking `select()` or using in-process dict storage, inspectable via `db_driver_mode()`), mutex-backed dynamic actor queues, constant-time modular Schnorr/Pedersen operations, and exploratory `pq_*`/`zk_*` research primitives emitted inline by `get_runtime_header()`.

### 1.4 Conformance Levels and Verification Boundaries

A conforming NinoLang v1.2 toolchain (`ninoc v1.2.5`) targets freestanding-style C11 source output compiled into native machine executables via GCC (default), LLVM-Clang (`--backend=llvm`), or the self-hosted Direct Machine-Code Backend (`--backend=native`, `--backend=native-pe`, `--backend=native-elf`, `--backend=native-arm64`), supporting standard `//` and `/* ... */` comments with zero em/en dashes. Validated locally and in CI across 29 native test suites (including the 16-part conformance suite `tools/iso_conformance.nino`) and a 161-test cross-platform Tier 1-4 E2E suite (`tests/e2e/`).

#### 1.4.1 Normative Guarantees Enforced by Compiler and Runtime

The compiler and emitted runtime enforce the following invariants:

1. **Delimiter Balance**: Unquoted `( )`, `{ }`, and `[ ]` SHALL be balanced (`verify_syntax_balance`, ignoring `//` and `/* ... */` comments).
2. **Linked AST Construction (`ninoc ast`) & Semantic Analysis (`ninoc check`)**: `expr_find_split_once` performs single-pass O(N) operator splitting during lowering, and `ast_build_internal` constructs an in-memory parent/depth/child-indexed (`p=`, `l=`, `r=`) AST (`PROGRAM`, `STRUCT_DECL`, `FN_DECL`, `PARAM`, `LET_DECL`, `MUT_DECL`, `BIN_OP`, `CALL_EXPR`, `INDEX_EXPR`, literals, and identifiers). Before transpilation or proving, `run_semantic_type_check` SHALL reject duplicate top-level `fn`/`struct` definitions (`E0428`), explicit binding/return primitive type contradictions (`E0308`), mismatched user function call arities (`E0061`), transitive un-unsealed `sealed` leaks across `print`, file, and network sinks (`E0042`), and unpinned region use after `arena_rollback()` (`E0515`, escapable safely via `region_pin(s)`).
3. **Scalar `let` Immutability (`E0384`)**: Direct reassignment of an in-scope variable declared with `let`, indexed element mutations on immutable `let` or non-`mut` slice parameters, and passing immutable `let` bindings into `mut` reference/writeback parameters SHALL fail compilation with diagnostic `E0384` (Clause 4.3).
4. **Runtime Array Bounds Safety, UAR Epoch Traps & Active NIR Passes**: Indexed read and write expressions (`a[i]`) use typed 48-byte `NinoArrHdr` metadata (`{ magic, origin, cap, len, reset_gen, mark_id }`) and emit `nino_bounds_check`, trapping with exit code `1` on null pointers (`CWE-119`), out-of-range indices (`CWE-125/787`), or rolled-back/invalidated array epochs (`CWE-416`, including on `push`/`pop`). `nir_optimize_normalized` prunes dead top-level statements after `return`, folds pure 64-bit constant arithmetic expressions, simplifies safe integer algebraic identities (`x + 0`, `x - 0`, `x * 1`, `x * 0`), proves `0..len(arr)` `@bce_pair` elision (invalidated automatically across `arena_rollback`, `arena_reset`, array-alias mutation, or user function calls), and reports live pass counts (`nir_stats_summary`).
5. **Runtime Contract Traps**: `require(cond, msg)` and `ensure(cond, msg)` emit `nino_require` and `nino_ensure`, terminating the process with exit code `1` if `cond` evaluates to `false`.
6. **Bounded Fail-Closed PCC Gating (`--proof`, `--bv`, `--int-logic`)**: All compiler Z3 invocations enforce `-T:15 -t:10000` resource bounds to prevent solver hangs. Under `--proof` / `--proof-bv` (and `--shared --proof`), PCC defaults to `QF_BV+64bit-Overflow` (with `--int-logic` selecting `ALL/QF_NIA+Array`) and SHALL fail closed with exit code `1` if zero `ensure(...)` / `invariant(...)` obligations exist, if Z3 is absent, or if Z3 returns `sat` / `unknown` / timeout (Clause 6.2).
7. **Deterministic GCC Codegen & `--strict-c11`**: Default GCC builds emit deterministic C11 with `-frandom-seed=42 -std=c11` (and `-Wl,--no-insert-timestamp` on Windows). Passing `--strict-c11` compiles with `-std=c11 -pedantic-errors -DNINO_STRICT_C11=1`, emitting zero GNU extensions (`__auto_type`, `__typeof__`, statement expressions `({ ... })`, `__asm__`, `__uint128_t`) and using `<stdatomic.h>` atomics for threading.

#### 1.4.2 C11 Backend Delegation

Type checking of struct member existence and field types, non-primitive compound expressions, generics, and `const` correctness of structs are delegated to the C11 compiler (`gcc` or `clang`), complementing the frontend static semantic checker (`E0428`, `E0308`, `E0061`, `E0042`, `E0515`, `E0384`). Default GCC builds pass `-Wall -Wextra` while suppressing unused parameter, variable, function, and set-parameter warnings; `--strict-c11` additionally enables `-pedantic-errors`.

#### 1.4.3 Lowering Boundaries and Embedded Runtime Subsystems

The following constructs operate with specific C11 lowering boundaries across the modular compiler (`compiler/*.nino`):

1. **`#no_std` Directive**: Suppresses implicit stdlib wrapper emission at the Nino source level (`transpile_line`), while `get_runtime_header()` emits standard C11 headers (`<stdio.h>`, `<stdlib.h>`, `<stdint.h>`, `<stdbool.h>`, `<string.h>`, `<math.h>`, `<time.h>`, `<iso646.h>`, `<setjmp.h>`, `<stddef.h>`), Windows headers under `_WIN32` (`<winsock2.h>`, `<ws2tcpip.h>`, `<io.h>`, `<fcntl.h>`, `<windows.h>`, `<bcrypt.h>`), and POSIX headers under `#else` (`<unistd.h>`, `<pthread.h>`, `<fcntl.h>`, `<sys/types.h>`, `<sys/socket.h>`, `<sys/select.h>`, `<sys/mman.h>`, `<netinet/in.h>`, `<arpa/inet.h>`, `<netdb.h>`, `<signal.h>`, `<errno.h>`, `<dlfcn.h>`).
2. **`with capability [...]`**: Parsed as function signature metadata and stripped during C11 lowering.
3. **`inline_asm { ... }`**: Lowered to a scoped C block; `cpu_get_cycles` returns `QueryPerformanceCounter` ticks on Windows and `clock_gettime(CLOCK_MONOTONIC)` nanoseconds on POSIX.
4. **`comptime { ... }`**: Lowered to a scoped C block.
5. **`actor <Name> { receive(msg) { ... } }`**: Lowered to actor descriptors backed by the mutex-synchronized dynamic actor table (`_nino_actors` / `spawn_actor`, dynamically resizable ring inbox `actor_send` / `actor_receive` / `actor_inbox_len`, `spawn_supervisor`, `supervisor_dispatch`, `actor_patch`) alongside OS threads (`thread_spawn` / `thread_join`).
6. **`extern fn ... from "<lib>"`**: Emits C11 foreign function prototypes; dynamic runtime library loading is provided by `dylib_open`, `dylib_sym`, `dylib_call_*`, and `dylib_close`.
7. **Hybrid Drivers & Experimental Research Subsystems**:
   - **Database & Cache Drivers**: `db_postgres_*` communicates over TCP using PostgreSQL v3 StartupMessage, Cleartext/MD5 password auth (`user:pass` / `PGPASSWORD`), and `'Q'/'T'/'D'/'C'/'E'/'Z'` framing (`native:postgres-wire`), failing closed (`""`, `-1`, `"disconnected"`) when offline rather than falling back to SQLite; `db_sqlite_*` dynamically resolves `sqlite3.dll`/`libsqlite3.so` via `LoadLibraryA`/`dlopen` when installed on the host (`native:sqlite3`) and falls back transparently to a dynamically resizable in-memory SQL subset (`embedded:sqlite-mem`); `db_redis_*` attempts a 50ms non-blocking TCP RESP-2 connection (`native:redis-tcp`) and falls back transparently to an in-memory dict (`embedded:redis-mem`), all inspectable via `db_driver_mode(handle)`.
   - **Experimental Modules**: `pq_*` (constant-time modular arithmetic `_nino_ct_add_mod`/`_nino_mod_mul`/`_nino_mod_pow`/`_nino_ct_streq` for 61-bit Safe-Prime Schnorr signatures plus self-contained `RLWE64`/`MLKEM512` research KEMs), `zk_*` (Pedersen + 48-bit CDS OR-Sigma proofs), `std/wasm.nino` (WebAssembly v1 LEB128 binary section parser for Sections 1/3/5/6/7/10/11 and structured control-flow stack VM with div-by-zero and OOB memory traps), `std/mpc.nino` (Shamir Secret Sharing over 61-bit Mersenne prime `2305843009213693951` with overflow-safe modular arithmetic and CM elliptic-curve Feldman VSS verification using `D=43` curve order `M61`), `std/z3.nino` (dynamic `libz3` FFI returning zero/null handles safely when missing), and `enclave_attest()` (`software_process_sha256` measurement of the running binary with `hardware_tee="false"`) are scoped as research subsystems rather than certified production cryptography or hardware TEE silicon isolation.

#### 1.4.4 Host and Target Platform Notes

`compiler/common.nino` detects the host operating system at runtime via `is_host_windows()` (probing `OS == "Windows_NT"`, `WINDIR`, `SystemRoot`, or `C:\Windows\System32\cmd.exe`):

- **Windows Hosts**: `default_exe_name` appends `.exe`; `prepare_run_cmd` normalizes `/` to `\`; `delete_temp_file` falls back to `del /f /q ... >nul 2>&1`; `compile_nino_unit_ex` links `-lm -lgdi32 -luser32 -lbcrypt -lws2_32` and passes `-Wl,--no-insert-timestamp` (GCC) or `-target x86_64-pc-windows-gnu` plus `get_clang_include_opt()` (Clang).
- **POSIX Hosts (Linux and macOS)**: `default_exe_name` strips `.nino` (or appends `.out`); `prepare_run_cmd` prepends `./` for bare filenames; `delete_temp_file` falls back to `rm -f ... >/dev/null 2>&1`; `compile_nino_unit_ex` links `-lm -lpthread` and omits `-Wl,--no-insert-timestamp`, `-target x86_64-pc-windows-gnu`, and Win32 libraries. `print_version` reports the detected host target (`x86_64-pc-windows-gnu` on Windows or `x86_64-unknown-linux-gnu` on Linux).

## Clause 2: Lexical Grammar, Preprocessing, and Deterministic Finite Automaton (DFA)

### 2.1 Two-Phase Source Preprocessing

Before C11 transpilation, `transpile_to_c_pcc` executes two deterministic preprocessing passes over the raw UTF-8 source text.

#### 2.1.1 Phase 1: Import Resolution and Cycle-Safe Expansion

`expand_all_imports(source, visited, base_dir)` (`compiler/ninoc.nino:545-581`) processes the source line by line:

1. Each line is trimmed of leading and trailing whitespace (`is_space`: `' '`, `'\t'`, `'\r'`, `'\n'`).
2. If a trimmed line matches `starts_with(line, "import \"") && ends_with(line, "\"")`, the path operand `imp` is extracted (`slice(line, 8, len(line) - 9)`).
3. `resolve_import_path(imp, base_dir)` (`compiler/ninoc.nino:464-543`) resolves `imp` using the following ordered probe sequence:
   a. Append `".nino"` if `imp` does not end with `".nino"`.
   b. If `target` starts with `"pkg/"` or `"@pkg/"`, normalize `"@pkg/"` to `"pkg/"`; return `p_target` if it exists, otherwise `<p_target_without_ext>/module.nino` if it exists.
   c. Probe `base_dir + "/" + target`, then `base_dir + "/../" + target`, then `target` (relative to current working directory).
   d. Let `env_nino = get_env("NINO_HOME")` and `exe_dir = get_directory_of(argv(0))`. If `target` does NOT start with `"std/"`, probe `"std/" + target` under `base_dir`, `base_dir + "/.."`, `"."`, `env_nino`, `exe_dir`, and `exe_dir + "/.."`. If `target` DOES start with `"std/"`, probe `target` under `env_nino`, `exe_dir`, and `exe_dir + "/.."`.
   e. If no path matches, return `target`.
4. **Cycle Guard**: The expander maintains a pipe-delimited set `cur_visited` of `|<actual_path>|` tokens. If `|<actual_path>|` is already in `cur_visited`, the import is skipped to prevent infinite recursion.
5. **Inline Splicing**: If `file_exists(actual_path)` is true, the target file is read, recursively expanded via `expand_all_imports(imp_source, cur_visited, get_directory_of(actual_path))`, and spliced inline. If `file_exists(actual_path)` is false, the import expands to the empty string without raising a preprocessor error.
6. Non-import lines are emitted trimmed, separated by `"\n"`.

#### 2.1.2 Phase 2: Line Normalization and Multi-Line Joining

`normalize_and_join_lines(source)` (`compiler/ninoc.nino:583-632`) converts `"\r\n"` to `"\n"`, trims every line, and joins multi-line expressions into single logical lines:

1. A line is a **trailing-operator continuation** (`is_op_cont`) if it ends with any of: `+`, `-`, `*`, `/`, `%`, `&&`, `||`, `=`, `==`, or `!=`.
2. A line is a **block header** (`is_block_def`) if it begins with any of:
   `"struct "`, `"fn "`, `"if "`, `"while "`, `"for "`, `"else"`, `"} else"`, `"match "`, `"guard "`, `"transact"`, `"compensate"`, `"} compensate"`, `"actor "`, `"comptime"`, `"inline_asm"`, `"receive"`.
   (Implementation note: `starts_with(raw_line, "transact")` matches `"transaction"` as well, whereas `"} rollback"` is recognized by `transpile_line` but is absent from `is_block_def`.)
3. Multi-line accumulation starts (`in_multi_expr = true`) when a trimmed line satisfies `is_op_cont`, ends with `"("`, ends with `"["`, or ends with `"{"` while NOT matching `is_block_def`.
4. Subsequent trimmed lines are concatenated with a single space `" "` until `!is_op_cont` AND `(count("(") - count(")") <= 0)` AND `(count("{") - count("}") <= 0)` AND `(count("[") - count("]") <= 0)` across the accumulated buffer. Any pending buffer at EOF is flushed.

#### 2.1.3 Standalone `#no_std` Directive and Standard Comments

- **`#no_std`**: Recognized as a standalone directive line (`starts_with(line, "#no_std")` outside block comments) and omitted from C output. `#no_std` is a language directive, not a comment.
- **Line & Block Comments**: Standard `//` line comments, `///` documentation comments, and multi-line `/* ... */` block comments are supported throughout `.nino` source files outside string literals.
- **Compiler Comment Handling**: `expand_imports_rec`, `source_has_nostd_directive`, `verify_syntax_balance`, `lex_count_tokens`, `lex_dump_tokens`, `format_nino_source`, `transpile_line`, `lsp_analyze_diagnostics`, and `tools/compliance_check.nino` uniformly skip `//` and `/* ... */` comments outside strings, rejecting unclosed `/*` or unmatched `*/` comments and non-`#no_std` `#` lines.

### 2.2 Formal Lexical Grammar (ISO/IEC 14977 EBNF)
In the lexical grammar below, `"x".."y"` denotes the inclusive ASCII code-point range from `x` to `y`.
```ebnf
token_stream      = { whitespace | token } ;
whitespace        = " " | "\t" | "\r" | "\n" ;

token             = string_literal
                  | word_token
                  | two_char_op
                  | one_char_op
                  | delimiter ;

word_token        = keyword | number_literal | identifier ;

letter            = "A".."Z" | "a".."z" ;
digit             = "0".."9" ;
hex_digit         = digit | "A".."F" | "a".."f" ;
word_char         = letter | digit | "_" ;
newline           = "\n" | "\r\n" ;

identifier        = ( letter | "_" ) , { word_char } ;
number_literal    = digit , { word_char } ;
integer_literal   = [ "-" ] , ( digit , { digit } | ( "0x" | "0X" ) , hex_digit , { hex_digit } ) ;

keyword           = "fn" | "let" | "mut" | "if" | "else" | "while" | "for"
                  | "in" | "return" | "struct" | "match" | "require" | "ensure"
                  | "sealed" | "unseal" | "true" | "false" | "int" | "string"
                  | "bool" | "float" | "void" ;

string_literal    = '"' , { string_char | escape_pair } , '"' ;
char_literal      = "'" , ( escape_pair | ? any single character except "'" and "\" ? ) , "'" ;
escape_pair       = "\" , ? any single character ? ;
string_char       = ? any character except '"' and '\' ? ;

two_char_op       = "==" | "!=" | "<=" | ">=" | "&&" | "||"
                  | "<<" | ">>" | "->" | ".." | "=>" ;

one_char_op       = "+" | "-" | "*" | "/" | "%" | "=" | "<" | ">" | "!" ;

delimiter         = "(" | ")" | "{" | "}" | "[" | "]" | "," | ":" | ";"
                  | "." | "#" | "|" | "&" | ? any other single non-whitespace char ? ;
```

### 2.3 Deterministic Finite Automaton (DFA) Specification

The lexical scanner (`lex_dump_tokens`, `lex_count_tokens`) operates as a deterministic finite automaton `M = (Q, Sigma, delta, q0, F)` over UTF-8 byte input with 1-character lookahead.

#### 2.3.1 Alphabet Partition (`Sigma`)

- `WS`: `{ ' ', '\t', '\r', '\n' }`
- `Q`: `{ '"' }`
- `BS`: `{ '\\' }`
- `ALPHA_US`: `[A-Za-z_]`
- `DIGIT`: `[0-9]`
- `WORD`: `ALPHA_US U DIGIT`
- `SYM`: All remaining printable/control characters outside `WS`, `Q`, and `WORD`
- `EOF`: End of input buffer (`pos == slen`)

#### 2.3.2 State Set (`Q`) and Accepting Categories (`F`)

- `S0` (Start / Idle state)
- `S_STR` (Inside string literal, consuming body)
- `S_ESC` (Inside string literal immediately after `'\\'`)
- `S_WORD` (Accumulating `[A-Za-z0-9_]+`)
- `S_SYM` (Inspecting 1-char or 2-char symbol sequence)
- Accepting token emissions:
  - `ACC_STR` -> `STRING_LITERAL`
  - `ACC_WORD` -> `KEYWORD` (if `is_nino_keyword(w)`), else `NUMBER_LITERAL` (if `w[0] in DIGIT`), else `IDENTIFIER`
  - `ACC_OP2` -> `OPERATOR` (maximal munch 2-char match in `two_char_op`)
  - `ACC_OP1` -> `OPERATOR` (1-char match in `one_char_op`)
  - `ACC_DELIM` -> `DELIMITER` (any other 1-char `SYM`)

#### 2.3.3 Transition Table (`delta`)

| Current State | Input Class | Action / Lookahead | Next State | Emitted Token |
|---|---|---|---|---|
| `S0` | `WS` | Advance `pos += 1` | `S0` | None |
| `S0` | `Q` | Record `start = pos`, `pos += 1` | `S_STR` | None |
| `S0` | `WORD` | Record `start = pos`, `pos += 1` | `S_WORD` | None |
| `S0` | `SYM` | Enter symbol lookahead | `S_SYM` | None |
| `S0` | `EOF` | Halt | Halt | None |
| `S_STR` | `BS` | Advance `pos += 1` | `S_ESC` | None |
| `S_STR` | `Q` | Advance `pos += 1` | `S0` | `STRING_LITERAL` |
| `S_STR` | `EOF` | Terminate string (unterminated allowed by scanner) | `S0` | `STRING_LITERAL` |
| `S_STR` | Any other | Advance `pos += 1` | `S_STR` | None |
| `S_ESC` | `EOF` | Advance `pos` to `slen` | `S0` | `STRING_LITERAL` |
| `S_ESC` | Any char | Advance `pos += 1` (total +2 from `'\\'`) | `S_STR` | None |
| `S_WORD` | `WORD` | Advance `pos += 1` | `S_WORD` | None |
| `S_WORD` | Non-`WORD` or `EOF` | Do not consume lookahead; classify `word` | `S0` | `KEYWORD` / `NUMBER_LITERAL` / `IDENTIFIER` |
| `S_SYM` | `slice(pos, 2) in two_char_op` | Advance `pos += 2` | `S0` | `OPERATOR` (2-char) |
| `S_SYM` | `slice(pos, 1) in one_char_op` | Advance `pos += 1` | `S0` | `OPERATOR` (1-char) |
| `S_SYM` | Other `SYM` | Advance `pos += 1` | `S0` | `DELIMITER` (1-char) |

### 2.4 Keyword Classification and Discrepancies

`is_nino_keyword` classifies **exactly 22 keywords**:

```
fn, let, mut, if, else, while, for, in, return, struct, match,
require, ensure, sealed, unseal, true, false, int, string, bool, float, void
```

All other alphabetic words recognized by downstream passes (`import`, `extern`, `from`, `morphic`, `defer`, `guard`, `transact`, `transaction`, `compensate`, `rollback`, `abort`, `actor`, `receive`, `inline_asm`, `comptime`, `print`, `step`, `with`, `capability`, `and`, `or`, `not`, `i32`, `i64`, `u32`, `u64`, `u8`, `byte`, `f32`, `f64`, `str`, `any`, `dict`, `list`, `Option`, `Result`, `Pair`, `Box`, `Stack`, `Queue`, `Array`) act as **contextual keywords**: they are emitted as `IDENTIFIER` by `lex_dump_tokens` and interpreted syntactically by `transpile_line`, `transpile_expr`, and `map_type`.

**Observed Lexical Notes in `compiler/lexer_parser.nino` & `compiler/c_codegen.nino`:**

1. **`=>` in `lex_count_tokens`**: `lex_dump_tokens` (`compiler/lexer_parser.nino`) matches all 11 two-character operators including `"=>"`, whereas `lex_count_tokens` (`compiler/c_codegen.nino`) omits `"=>"` and counts it as two single-character tokens (`=` and `>`).
2. **`|>` Pipeline Operator**: Neither `lex_count_tokens` nor `lex_dump_tokens` treats `"|>"` as a two-character token; it is lexed as `DELIMITER('|')` followed by `OPERATOR('>')` and matched at statement level by `transpile_line`.
3. **Decimal Float Literals**: Because `'.'` is not in `WORD`, a decimal literal such as `3.14` is scanned by the DFA lexer as three tokens (`NUMBER_LITERAL(3)`, `DELIMITER('.')`, `NUMBER_LITERAL(14)`), while hexadecimal integer literals (`0xDEADC0DE`) scan as a single `NUMBER_LITERAL`. `transpile_expr` passes `3.14` directly to C11.

### 2.5 String Interpolation (`"{expr}"`) and Delimiter Balance

#### 2.5.1 String Interpolation

When `transpile_expr` encounters a pure string literal (`is_pure_string_literal` in `compiler/common.nino`: starts and ends with unescaped `"` with no unescaped `"` inside), `expand_string_interp` (`compiler/common.nino`) scans the literal body for `{expr}` segments:

- `expand_string_interp` scans `inner` character-by-character and checks `ch == "{"` directly without checking for a preceding backslash (`\`); thus `\{` is NOT treated as an escape sequence (`"\{x}"` is interpolated as `"\" + (x)` if `x` satisfies `is_interp_expr`).
- When `{...}` is found, `is_interp_expr(expr)` (`compiler/ninoc.nino:634-672`) validates `expr`. Expansion is rejected (keeping `{...}` literal, e.g., JSON strings) if ANY of the following holds:
  1. `expr` is empty.
  2. `expr` contains `;`, `\n`, `{`, or `}`.
  3. `expr` starts with `"if "`, `"return "`, `"struct "`, `"static "`, `"typedef "`, `"void "`, or `"NULL"`.
  4. `expr` contains a top-level `,` (at `paren_depth <= 0`).
  5. `expr` contains an unescaped `"`.
  6. `expr` has unbalanced parentheses (`paren_depth != 0`).
- Inside a valid `{expr}`, escaped `\"` sequences are unescaped to `"`, and `"pre{expr}post"` is rewritten into `"pre" + (expr) + "post"`, which is then recursively passed to `transpile_expr` (triggering `_Generic` auto-concatenation per Clause 4.2).

#### 2.5.2 Delimiter Balance Verification

`verify_syntax_balance` scans the raw source prior to lexing and compilation, tracking `p_depth` (`(` / `)`), `b_depth` (`{` / `}`), and `br_depth` (`[` / `]`) outside `"..."` strings (respecting backslash parity before `"`). Any negative depth aborts immediately with line number and exit code `1`; non-zero depth at EOF aborts with an unclosed delimiter error.

## Clause 3: Syntactic Grammar and Precedence-Climbing Expression Specification

### 3.1 Formal Syntactic Grammar (ISO/IEC 14977 EBNF)

Statements in Nino are line-oriented after `normalize_and_join_lines` (one statement or block header per logical line, with optional trailing `;`).

```ebnf
compilation_unit  = { top_level_item } ;

top_level_item    = no_std_directive
                  | import_decl
                  | extern_fn_decl
                  | struct_decl
                  | actor_decl
                  | fn_decl
                  | var_decl ;

no_std_directive  = "#no_std" ;
import_decl       = "import" , string_literal ;

extern_fn_decl    = "extern" , "fn" , identifier , "(" , [ param_list ] , ")" ,
                    [ "->" , type_expr ] , [ "from" , string_literal ] ;

struct_decl       = "struct" , identifier , "{" , [ struct_fields_inline ] , "}"
                  | "struct" , identifier , "{" , newline , { struct_field_line } , "}" ;
struct_fields_inline = struct_field , { "," , struct_field } ;
struct_field_line = struct_field , [ "," ] , newline ;
struct_field      = [ "mut" ] , identifier , ":" , type_expr ;

actor_decl        = "actor" , identifier , "{" , newline ,
                    [ "receive" , "(" , identifier , ")" , "{" , newline , { statement } , "}" , newline ] ,
                    "}" ;

fn_decl           = "fn" , identifier , "(" , [ param_list ] , ")" ,
                    [ "->" , type_expr , [ "with" , "capability" , [ capability_list ] ] ] ,
                    ( "{" , [ statement ] , "}"
                    | "{" , newline , { statement } , "}" ) ;
param_list        = param , { "," , param } ;
param             = [ "mut" ] , identifier , ":" , type_expr ;
capability_list   = "[" , [ identifier , { "," , identifier } ] , "]" | identifier ;

type_expr         = primitive_type
                  | "[" , type_expr , "]"
                  | "Array" , "<" , type_expr , ">"
                  | "Option" , "<" , type_expr , ">"
                  | "Result" , "<" , type_expr , "," , type_expr , ">"
                  | "Pair" , "<" , type_expr , "," , type_expr , ">"
                  | "Box" , "<" , type_expr , ">"
                  | "Stack" , "<" , type_expr , ">"
                  | "Queue" , "<" , type_expr , ">"
                  | identifier ;

primitive_type    = "int" | "i64" | "i32" | "u32" | "u64" | "byte" | "u8"
                  | "float" | "f64" | "f32" | "bool" | "string" | "str"
                  | "void" | "any" | "dict" | "list" ;

statement         = ( var_decl
                    | assign_stmt
                    | defer_stmt
                    | guard_stmt
                    | if_stmt
                    | while_stmt
                    | for_stmt
                    | match_stmt
                    | transact_stmt
                    | abort_stmt
                    | contract_stmt
                    | inline_asm_stmt
                    | comptime_stmt
                    | print_stmt
                    | return_stmt
                    | pipeline_stmt
                    | expr_stmt ) , [ ";" ] ;

var_decl          = ( "let" | "mut" ) , identifier , [ ":" , type_expr ] , "=" , expr
                  | "sealed" , "let" , identifier , "=" , expr
                  | "morphic" , "mut" , identifier , "=" , expr ;

assign_stmt       = lvalue , "=" , expr ;
lvalue            = identifier | expr , "[" , expr , "]" ;

defer_stmt        = "defer" , statement ;
guard_stmt        = "guard" , expr , "else" , "{" , newline , { statement } , "}" ;

if_stmt           = "if" , expr , "{" , statement , "}"
                  | "if" , [ "!" ] , expr , "{" , newline , { statement } , "}" ,
                    { [ "}" ] , "else" , "if" , expr , "{" , newline , { statement } , "}" } ,
                    [ [ "}" ] , "else" , "{" , newline , { statement } , "}" ] ;

while_stmt        = "while" , expr , "{" , newline , { statement } , "}" ;

for_stmt          = "for" , identifier , "in" , expr , ".." , expr , [ "step" , expr ] ,
                    "{" , newline , { statement } , "}"
                  | "for" , identifier , "in" , expr ,
                    "{" , newline , { statement } , "}" ;

match_stmt        = "match" , expr , "{" , newline , { match_arm } , "}" ;
match_arm         = ( pattern | "_" ) , "=>" , statement , [ "," ] , newline ;
pattern           = integer_literal | identifier | char_or_const ;
char_or_const     = char_literal | integer_literal ;

transact_stmt     = ( "transact" | "transaction" ) , "{" , newline , { statement } ,
                    "}" , ( "compensate" | "rollback" ) , "{" , newline , { statement } , "}" ;

abort_stmt        = "abort" , expr | "abort" , "(" , expr , ")" ;

contract_stmt     = "require" , "(" , expr , "," , expr , ")"
                  | "ensure" , "(" , expr , "," , expr , ")" ;

inline_asm_stmt   = "inline_asm" , "{" , newline , { "rdtsc" | "cpuid" | statement } , "}" ;
comptime_stmt     = "comptime" , "{" , newline , { statement } , "}" ;

print_stmt        = "print" , "(" , expr , { "," , expr } , ")" ;
return_stmt       = "return" , [ expr ] ;

pipeline_stmt     = expr , "|>" , pipeline_stage , [ "|>" , pipeline_stage ] ;
pipeline_stage    = identifier , [ "(" , ")" ] ;

expr_stmt         = expr ;
```

### 3.2 Precedence-Climbing Expression Grammar

Binary operator precedence is governed by `get_op_precedence` (`compiler/ninoc.nino:2762-2770`) and lowered recursively by `transpile_expr` (`1007-1423`):

| Level | Operators | Associativity | Category |
|---|---|---|---|
| 1 (Lowest) | `\|\|`, `or` | Left-to-right (`\|\|` tested before `or`) | Logical OR |
| 2 | `&&`, `and` | Left-to-right (`&&` tested before `and`) | Logical AND |
| 3 | `==`, `!=`, `<`, `<=`, `>`, `>=` | Sequential scan (`==`, `!=`, `<=`, `>=`, `<`, `>`) | Equality and Relational |
| 4 | `<<`, `>>` | Sequential scan (`<<` tested before `>>`) | Bitwise Shift |
| 5 | `+`, `-` | Left-to-right (rightmost operator in tier) | Additive / String Concat |
| 6 (Highest Binary) | `*`, `/`, `%` | Left-to-right (rightmost operator in tier) | Multiplicative |

Formal expression EBNF:

```ebnf
expr              = or_expr ;
or_expr           = and_expr , { ( "||" | "or" ) , and_expr } ;
and_expr          = rel_expr , { ( "&&" | "and" ) , rel_expr } ;
rel_expr          = shift_expr , { ( "==" | "!=" | "<" | "<=" | ">" | ">=" ) , shift_expr } ;
shift_expr        = add_expr , { ( "<<" | ">>" ) , add_expr } ;
add_expr          = mul_expr , { ( "+" | "-" ) , mul_expr } ;
mul_expr          = unary_expr , { ( "*" | "/" | "%" ) , unary_expr } ;

unary_expr        = ( "not" | "!" | "-" | "+" ) , unary_expr
                  | postfix_expr ;

postfix_expr      = primary_expr , { call_suffix | index_suffix | member_suffix } ;
call_suffix       = "(" , [ arg_list ] , ")" ;
index_suffix      = "[" , expr , "]" ;
member_suffix     = "." , identifier ;
arg_list          = expr , { "," , expr } ;

primary_expr      = "(" , expr , ")"
                  | builtin_call
                  | array_literal
                  | dict_literal
                  | struct_literal
                  | string_literal
                  | number_literal
                  | "true" | "false"
                  | identifier ;

builtin_call      = ( "len" | "argc" | "char_code" | "read_file" | "file_exists"
                    | "file_delete" | "exec_cmd" | "argv" | "char_at"
                    | "slice" | "write_file" ) , "(" , [ arg_list ] , ")" ;

array_literal     = "[" , [ expr , { "," , expr } ] , "]" ;
dict_literal      = "{" , [ dict_entry , { "," , dict_entry } ] , "}" ;
dict_entry        = expr , ":" , expr ;
struct_literal    = identifier , "{" , [ field_init , { "," , field_init } ] , "}" ;
field_init        = identifier , ":" , expr ;
```

### 3.3 Function Signatures, `defer`, `mut` Parameters, and Parser Reconciliation

1. **`fn main` Signature**: `fn main(...)` always emits `int main(int argc, char** argv) { nino_init_args(argc, argv);`. If no `fn main` is present in a compilation unit, the transpiler synthesizes an empty `int main(int argc, char** argv)` returning `0`.
2. **`defer` LIFO Execution**: Statements registered with `defer <stmt>` inside a function are recorded in a function-local list and emitted in reverse (LIFO) order immediately before each `return` statement and upon reaching the closing `}` of the function body.
3. **`mut` Parameter Passing**: During symbol pre-scanning (`collect_string_symbols`), any `mut p: T` parameter at any parameter position (`0, 1, 2, ...`) whose mapped C type `mapped_T` is neither a scalar primitive nor a pointer records `@mut_param:<fn_name>:<param_idx>|`. In `transpile_params`, each such parameter emits `mapped_T* _nino_ptr_<p>`. Inside the function body, entry initializes a local working copy (`mapped_T <p> = _nino_ptr_<p> ? *_nino_ptr_<p> : (mapped_T){0};`), automatic writeback (`if (_nino_ptr_<p>) *_nino_ptr_<p> = <p>;`) runs prior to every `return` statement, single-line `if cond { return ... }`, and the function closing `}`, and call sites rewrite argument `arg_idx` to `&(<arg>)`. No C preprocessor `#define` macros are emitted.
4. **Struct Hoisting**: All `struct` declarations are hoisted into `struct_code` and emitted prior to function bodies in C11 output, enabling forward references among structs.
5. **Tagged AST Builder (`ast_build_internal` & `parse_program_ast`)**: Construct an in-memory N-ary node table (`PROGRAM`, statements, declarations, parameters, and precedence-split `BIN_OP` / `CALL_EXPR` / `INDEX_EXPR` trees) via `ast_find_lowest_op` with explicit stack traversal, inspectable via `ninoc ast <file.nino>`.
   - `transpile_expr` lowers Nino expressions into C11 (`transpile_to_c_full`), supporting operator tiers `||`, `&&`, `==`/`!=`, relational ops, shifts, bitwise `|`/`^`/`&`, additive/multiplicative arithmetic, array/dict literals, calls, and `a[i]` indexing (with `@bce_pair` bounds elision inside verified `for i in 0..len(arr)` loops).
   - `|>` is supported both at statement level and as an expression-level left-to-right pipeline operator (Clause 9.7).
   - Ternary `cond ? a : b` and member access `a.b` are parsed into AST nodes and lowered cleanly in C11.

#### Normative Example (Nino Syntax)

```nino
struct Point {
    x: int,
    y: int
}

fn manhattan(p: Point) -> int {
    require(p.x >= 0 && p.y >= 0, "coordinates must be non-negative")
    let d = p.x + p.y
    ensure(d >= 0, "distance must be non-negative")
    return d
}

fn main() -> int {
    let origin = Point { x: 3, y: 4 }
    let dist = manhattan(origin)
    print("Distance: {dist}")
    return 0
}
```

## Clause 4: Static Semantics, Type System, and Soundness Boundaries

### 4.1 Type Algebra and C11 Representation Mapping (`map_type`)

`map_type(t)` (`compiler/ninoc.nino:187-284`) defines the authoritative mapping from Nino surface types to C11 target types:

| Nino Type Syntax | Lowering Rule / Condition | C11 Mapped Type |
|---|---|---|
| `int`, `i64` | Exact match | `int64_t` |
| `i32` | Exact match | `int32_t` |
| `u32` | Exact match | `uint32_t` |
| `u64` | Exact match | `uint64_t` |
| `byte`, `u8` | Exact match | `uint8_t` |
| `float`, `f64` | Exact match | `double` |
| `f32` | Exact match | `float` |
| `bool` | Exact match | `bool` |
| `string`, `str` | Exact match | `const char*` |
| `void` | Exact match | `void` |
| `any`, `dict`, `list` | Exact match | `void*` |
| `Array<T>` | Recursive `map_type("[" + T + "]")` | See `[T]` below |
| `[str]`, `[string]` | Element is `str` or `string` | `const char**` |
| `[void]`, `[any]` | Element maps to `void` or is `any` | `void**` |
| `[T]` | Other element type `T` | `<map_type(T)>*` |
| `Option<int>`, `Option<i64>` | Standard library `std/option.nino` | `OptionI64` |
| `Option<str>`, `Option<string>` | Standard library `std/option.nino` | `OptionStr` |
| `Option<T>` | Other `T` (monomorphized) | `Option_<T>` |
| `Result<int, E>`, `Result<i64, E>` | Standard library `std/result.nino` | `ResultI64` |
| `Result<str, E>`, `Result<string, E>` | Standard library `std/result.nino` | `ResultStr` |
| `Result<T, E>` | Other `T` (`E` omitted in type name) | `Result_<T>` |
| `Pair<T, U>` | Monomorphized | `Pair_<T>_<U>` |
| `Box<T>` | Monomorphized | `Box_<T>` |
| `Stack<T>` | Mapped only (see 4.4 caveat) | `Stack_<T>` |
| `Queue<T>` | Mapped only (see 4.4 caveat) | `Queue_<T>` |
| User type `Ident` | `struct`, `actor`, or typedef | `Ident` (verbatim) |

#### 4.1.1 Unannotated `let` / `mut` Type Inference

When a binding omits `: Type`:

- Empty array `[]` infers `void*` (`const void*` for `let`).
- Array starting with `"` (`["a", ...]`) infers `const char**`.
- Array literal containing `.` infers `double*` (`const double*` for `let`).
- Other non-empty array literals infer `int64_t*` (`const int64_t*` for `let`).
- `mut v = "..."` infers `const char*`.
- All other unannotated `mut` / `let` bindings emit explicit inferred C11 types (`int64_t`, `double`, `bool`, `const char*`, or struct types) under `--strict-c11`, or `__auto_type` / `const __auto_type` in default mode.

#### 4.1.2 Dynamic Array Runtime Header Layout

`_nino_alloc_arr`, `_nino_make_arr`, and `_nino_push_impl` use a 48-byte metadata header (`{ magic, origin, cap, len, reset_gen, mark_id }`) directly preceding element `0`, returning `(void*)(hdr + 1)`. Allocations default to `NinoArena` (recording `origin = g_nino_arena.total_offset`, `reset_gen`, `mark_id`, minimum `cap = 256` bytes). When `_nino_push_impl` grows capacity (`crosses_mark`) while `origin == -1` or `origin < g_nino_arena.marks[mark_depth - 1]`, it promotes the grown buffer onto the system heap (`calloc` / `realloc`, `origin = -1`, `reset_gen = 0`, `mark_id = 0`) and increments `_nino_heap_arr_live`, preventing Use-After-Rollback across active `arena_mark()` frames while allowing transient inner arrays to reclaim cleanly on `arena_rollback()`. Programmers may explicitly release heap-promoted arrays via `arr_free(arr)` (which validates `_NINO_ARR_MAGIC` and `origin == -1`, zeroes `cap`, frees the header base, decrements `_nino_heap_arr_live`, and acts as a safe no-op on null or arena-owned slices) and inspect live promoted allocations with `heap_live_arrays()`.

### 4.2 String Symbol Inference, `_Generic` Dispatch, and Runtime Bounds Guards

#### 4.2.1 `collect_string_symbols`

Before transpiling statements, `collect_string_symbols(normalized)` (`compiler/ninoc.nino:1032-1158`) initializes `res_str` with string-returning built-ins and emits `@fn:<name>|` tags for string-returning functions (`-> string` / `-> str`), `@str_arr:<name>|` tags for top-level string arrays (`[str]` / `[string]` / `Array<str>`), and `@mut_param:<fn>:<idx>|` tags for `mut` struct parameters. Function parameters and local variables are tracked at block depth `0` globally and scoped per function (`active_sub`) inside `transpile_to_c_pcc` (scrubbing `let`/`mut`, `for` induction variables, and lambda variables in `arr_map`/`arr_filter`/`arr_reduce`), preventing cross-function symbol pollution.

#### 4.2.2 `_Generic` String Concatenation, Printing, and `len()`

- **String Equality**: When `a == b` or `a != b` involves a string expression (`is_str_expr` or lowered prefix `nino_str_concat` / `nino_auto_concat`), `transpile_expr` lowers to `nino_str_eq(tl, tr)` or `(!nino_str_eq(tl, tr))`.
- **String Addition**: For `a + b`, if both sides are strings, `transpile_expr` emits `nino_str_concat(tl, tr)`; if only left is string, `nino_auto_concat(tl, tr)`; if only right is string, `nino_auto_concat_r(tl, tr)`; otherwise `(tl + tr)`. `_Generic` dispatches integer types via `%lld`, `double`/`float` via `%g` (appending `".0"` if no `.`, `e`, or `E` is present), and `bool` via `"true"`/`"false"`.
- **Printing**: Single-argument `print(X)` lowers to `nino_print(X)` via `_Generic`. Multi-argument `print(a, b, ...)` lowers to sequential `nino_print_val(arg)` calls followed by `printf("\n")`.
- **Length `len(X)`**: `_Generic` dispatches `char*` and `const char*` to `nino_len_str` (`strlen`), and pointer/array types to `nino_len_arr` (`((const int64_t*)p)[-1]`).

#### 4.2.3 Runtime Bounds Checking and Epoch Traps

Every indexed array read `target[idx]` and indexed write `target[idx] = val` (when `idx` does not start with `"` for dict lookup) emits `nino_bounds_check((void*)(t_target), (int64_t)(t_idx))`:

- If `arr == NULL`: prints `[Nino Bounds Violation CWE-119] Dereferencing null array` to `stderr` and terminates with `exit(1)`.
- If `_nino_arr_is_alive(arr)` is false (array `reset_gen` or `mark_id` was invalidated by `arena_rollback` or `arena_reset`): prints `[Nino Use-After-Rollback Violation CWE-416]` to `stderr` and terminates with `exit(1)` (likewise enforced on `_nino_push_impl` and `_nino_pop_impl`).
- Reads `len = nino_len_arr(arr)`; if `idx < 0 || idx >= len`: prints `[Nino Bounds Violation CWE-125/787] Index %lld out of bounds [0, %lld)` to `stderr` and terminates with `exit(1)`.
- `runtime/nino_runtime.h` is synchronized with `arena_ptr_valid`, `_nino_arr_is_alive`, `nino_bounds_check(void* arr, int64_t idx)`, and `nino_len_arr`.

### 4.3 Formal Typing Judgments and Static Enforcement (`E0384`, `E0042`)

Let `Gamma` map identifiers to `(tau, qual, depth)` where `qual in { imm, mut, sealed }`, and `Sigma_fn` denote the function-local `sealed_scope`. Judgments use ASCII turnstile notation `Gamma |- e : tau`.

#### 4.3.1 Core Expression and Binding Judgments

```text
[T-Int]
----------------------------------------
Gamma |- n : int    (n is decimal/hex integer)

[T-Float]
----------------------------------------
Gamma |- f : float  (f is floating literal)

[T-Bool]
----------------------------------------
Gamma |- b : bool   (b in {true, false})

[T-Str]
----------------------------------------
Gamma |- s : string (s is "..." with valid interpolations)

[T-Var]
(x : (tau, q, d)) in Gamma
--------------------------
Gamma |- x : tau

[T-Let]
Gamma |- e : tau_e    (tau == tau_e if annotated)
--------------------------------------------------
Gamma, x : (tau, imm, depth) |- let x [: tau] = e

[T-Mut]
Gamma |- e : tau_e    (tau == tau_e if annotated)
--------------------------------------------------
Gamma, x : (tau, mut, depth) |- mut x [: tau] = e

[T-Sealed]
Gamma |- e : tau_e
----------------------------------------------------------
Gamma, x : (tau_e, sealed, depth) |- sealed let x = e

[T-Unseal]
Gamma |- x : (string, sealed, d)
---------------------------------
Gamma |- unseal(x) : string

[T-Arr-Index]
Gamma |- a : [tau]    Gamma |- i : int    (i not string literal)
----------------------------------------------------------------
Gamma |- a[i] : tau   (guarded by runtime nino_bounds_check)

[T-Dict-Index]
Gamma |- d : dict     s is string literal
------------------------------------------
Gamma |- d[s] : string  (via nino_dict_get)

[T-App]
Gamma(f) = (tau_1, ..., tau_n) -> tau_r    Gamma |- e_k : tau_k  (for all k = 1..n)
----------------------------------------------------------------------------------
Gamma |- f(e_1, ..., e_n) : tau_r   (checked by C11 backend)
```

#### 4.3.2 Immutability Enforcement (`E0384`)

Inside a function (`in_fn == true`), `transpile_to_c_pcc` tracks lexical block depth `fn_depth` (starting at `1` on `fn ... {`, incremented on `{`, purged via `purge_depth` and decremented on `}`):

- `let_scope` records `fn_depth:vname|` for `let` bindings.
- `mut_scope` records `fn_depth:vname|` for `mut` bindings.
- On bare identifier assignment `vname = rhs` (excluding `let`/`mut`, `==`, `!=`, `<=`, `>=`): let `let_d = find_var_depth(let_scope, vname)` and `mut_d = find_var_depth(mut_scope, vname)`.

```text
[E0384-Reject]
let_d != -1  /\  let_d >= mut_d
-------------------------------------------------------------------------
Gamma |- vname = rhs  ===>  Compile Error E0384 (abort transpilation)
```

#### 4.3.3 Sealed Confidentiality Flow Enforcement (`E0042`)

- `sealed let vname = rhs` appends `vname|` to function-local `sealed_scope` (cleared when `fn_depth == 0`).
- On `print(arg)` inside a function:

```text
[E0042-Reject]
s_var in sealed_scope  /\  find_str(arg, s_var) != -1  /\  find_str(arg, "unseal(") == -1
-----------------------------------------------------------------------------------------
Gamma |- print(arg)  ===>  Compile Error E0042 (abort transpilation)
```

### 4.4 Generics Monomorphization (`monomorphize_generics`)

`monomorphize_generics(normalized)` (`compiler/ninoc.nino:2238-2360`) scans the normalized source for generic instantiations, deduplicates them via `seen`, and emits C11 `typedef struct` and `static inline` helpers between `struct_code` and `body_code`:

1. **`Option<T>`** (excluding `T` in `{T, E, U, i64, int, str, string}`):
   - Emits `Option_<T>` (`_Nino_Generic_Option_<T>` with `{ bool is_some; <c_t> val; }`), `some_<T>(val)`, `none_<T>()`, `Option_<T>_is_some(opt)`, and `Option_<T>_unwrap(opt)` (guarded by `nino_require(opt.is_some, (const char*)0)`).
   - `Option<int/i64>` and `Option<str/string>` use `std/option.nino` (`OptionI64`, `OptionStr`).
2. **`Result<T, E>`** (excluding `T`/`E` in `{T, E}` and `T` in `{i64, int, str, string}`):
   - Emits `Result_<T>` and alias `Result_<T>_<E>` (`_Nino_Generic_Result_<T>` with `{ bool is_ok; <c_t> ok_val; <c_e> err_val; }`), `ok_<T>(val)`, `err_<T>(err)`, `Result_<T>_is_ok(res)`, and `Result_<T>_unwrap(res)` (guarded by `nino_require(res.is_ok, res.err_val)`).
   - `Result<int/i64, E>` and `Result<str/string, E>` use `std/result.nino` (`ResultI64`, `ResultStr`).
3. **`Pair<T, U>`**: Emits `Pair_<T>_<U>` (`{ <c_p1> first; <c_p2> second; }`) and `make_pair_<T>_<U>(a, b)`.
4. **`Box<T>`**: Emits `Box_<T>` (`{ <c_t> val; }`) and `box_<T>(val)`.

**Monomorphization Boundaries**:

- `Stack<T>` and `Queue<T>` are mapped by `map_type` but have no generators in `monomorphize_generics` in v1.2.
- `Result<T, E>` deduplicates by `Result_<T>` only (ignoring `E`), so two distinct error types `E1 != E2` for the same `T` collide in one compilation unit, and `ok_<T>` initializes `err_val = (const char*)0` (assuming a pointer-compatible `E`).
- Nested generics (such as `Option<Box<int>>`) and user-defined generic functions `fn f<T>(...)` are not monomorphized because `is_valid_identifier` rejects `<` and `>`.

### 4.5 Soundness Arguments (Progress and Preservation) and Verification Boundaries

#### 4.5.1 Scoped Progress and Preservation

Within the subset of Nino programs that pass `ninoc` static checks (`verify_syntax_balance`, `E0384`, `E0042`) AND compile without errors or undefined-behavior diagnostics under C11 (`gcc`/`clang` with `-std=c11`):

- **Preservation**: Each Nino binding and expression maps deterministically to a C11 declaration or expression whose static C11 type is preserved across evaluation steps (`map_type`, explicit C11 declarations in `--strict-c11`, or `__auto_type` in default mode, plus monomorphized struct types). Mutations to `let`-bound identifiers are rejected statically (`E0384` for scalars, C11 `const` for typed structs/bindings).
- **Progress (Safe Evaluation or Fail-Stop Trap)**: A well-typed C11-lowered expression either reduces to a value of its C11 type or triggers a deterministic fail-stop trap (`exit(1)`) at runtime guards: `nino_bounds_check` / `_nino_arr_is_alive` (null pointer `CWE-119`, out-of-bounds index `CWE-125/787`, or rolled-back array epoch `CWE-416`), `nino_require` / `nino_ensure` (contract failure or `Option`/`Result` unwrap failure), or `nino_panic` / `nino_abort`. Under `--proof` (`unsat`), integer arithmetic contracts satisfy universal validity over 64-bit BitVectors (`QF_BV` default) or mathematical integers (`--int-logic`) prior to code emission (subject to Clause 6.4).

#### 4.5.2 Explicit Verification Boundaries

The following boundaries apply to v1.2 type and safety soundness:

1. **C11 Pointer and Raw Memory Semantics**: Raw pointer operations (`alloc_memory`, `foreign_alloc`, `write_byte`, `read_byte`), division by zero (`/` lowers directly to C `/`), and calling `len()` or `[]` on pointers lacking the 48-byte `NinoArrHdr` (`{ magic, origin, cap, len, reset_gen, mark_id }`) allocated by `_nino_alloc_arr`/`_nino_make_arr` inherit C11 behavior if misused. Under `--strict-c11`, `free_memory`/`write_byte`/`read_byte` accept direct `void*` operands cleanly without integer-to-pointer macro casts, and Zero GNU extensions (`__auto_type`, `__typeof__`, `({ ... })`, `__asm__`, `__uint128_t`) are emitted.
2. **Scoped Semantic Type & Lifetime Checker (`run_semantic_type_check`)**: Rejects `E0428` duplicate top-level symbols, `E0308` explicit primitive binding/return contradictions, `E0061` user function arity mismatches, `E0042` transitive sealed aliasing/sinks (including return-path taint propagation, excluding one-way cryptographic commitments `zk_*`, `zkp_*`, `sha256`, `hmac_sha256`, and `len`), and `E0515` unpinned region escapes across `arena_rollback()`. Compound struct field expressions and higher-order lambdas remain checked by the C11 backend.
3. **`E0384` Scope Boundaries**: `E0384` inspects bare identifier assignments `vname = ...` and indexed element mutations on immutable `let`-bound arrays (`arr[i] = ...`). Dynamic bounds checking and `const` struct bindings remain enforced at runtime/C11.

## Clause 5: Linear Memory Model, Scoped Arena Lifecycle, and CSPRNG Enclave

### 5.1 Thread-Local `NinoArena` Architecture and Operational Semantics

Dynamic runtime strings, dictionary structures, SHA-256 hex digests, TCP read buffers, stdio line/byte buffers, unsealed plaintext buffers, and intra-frame arrays allocate from a per-thread multi-slab bump arena `g_nino_arena` (`compiler/ninoc.nino:2235-2244`; `runtime/nino_runtime.h:127-246`):

```c
#if defined(_MSC_VER)
#define NINO_THREAD_LOCAL __declspec(thread)
#elif defined(__STDC_VERSION__) && __STDC_VERSION__ >= 201112L && !defined(__STDC_NO_THREADS__)
#define NINO_THREAD_LOCAL _Thread_local
#elif defined(__GNUC__) || defined(__clang__)
#define NINO_THREAD_LOCAL __thread
#else
#define NINO_THREAD_LOCAL
#endif

typedef struct NinoArenaSlab { char* data; size_t cap; size_t used; size_t base_offset; struct NinoArenaSlab* prev; } NinoArenaSlab;
typedef struct { NinoArenaSlab* tail; size_t total_offset; size_t marks[64]; uint64_t mark_ids[65]; uint64_t next_mark_id; uint64_t reset_gen; int mark_depth; } NinoArena;
static NINO_THREAD_LOCAL NinoArena g_nino_arena = {NULL, 0, {0}, {1ULL}, 2ULL, 1ULL, 0};
```

#### 5.1.1 Formal Operational Semantics

Let the per-thread arena state be a tuple `A = (tail, tot, marks, mark_ids, next_mark_id, reset_gen, depth)` where `tail` is the active 4 MiB (or larger) `NinoArenaSlab` head of a backward-linked slab chain (`base_offset` monotonically increasing), `tot` is the cumulative logical byte watermark `total_offset`, `marks[0..depth-1]` is the active mark stack (`depth <= 64`), `mark_ids[k]` records epoch IDs active per nesting level, and `reset_gen` increments on full resets.

1. **Initialization (`nino_arena_init(c)`)**: Frees any existing slab chain, sets `c' = c ? c : 4194304`, allocates a single `NinoArenaSlab` with `base_offset = 0`, `used = 0`, and resets `total_offset = 0`, `mark_depth = 0`, `mark_ids[0] = 1ULL`, `next_mark_id = 2ULL`.
2. **Allocation (`nino_arena_alloc(sz)`)**: Computes `asz = max(8, (sz + 7) & ~7)`. If `tail->used + asz <= tail->cap`, bumps `tail->used += asz` and `total_offset += asz` in O(1). Otherwise allocates a new `NinoArenaSlab` of size `max(4194304, asz)` linked via `prev = tail` with `base_offset = total_offset`.
3. **Mark (`arena_mark()`)**: Records `total_offset` onto `marks[mark_depth++]` (when `mark_depth < 64`), assigns `mark_ids[mark_depth] = next_mark_id++`, and returns `(int64_t)total_offset`.
4. **Scoped Rollback (`arena_rollback(m)`)**: Validates `0 <= m <= total_offset`, pops mark frames satisfying `marks[k] >= m` (shrinking `mark_depth` so popped `mark_ids` are no longer live in `mark_ids[0..mark_depth]`), frees every `NinoArenaSlab` whose `base_offset >= m` (and `base_offset > 0`), restores `tail->used = m - tail->base_offset`, and sets `total_offset = m`. Any arena array carrying a popped `mark_id` (or stale `reset_gen`) fails `_nino_arr_is_alive` (`arena_ptr_valid`), trapping deterministically on subsequent index/`push`/`pop` (`CWE-416`).
5. **Usage Inspection (`arena_used()`)**: Returns `(int64_t)g_nino_arena.total_offset`.
6. **Full Reset & Destruction (`nino_arena_reset()` / `_nino_arena_destroy()`)**: `nino_arena_reset()` frees all slabs above the root slab, zeroes `used` and `total_offset`, and increments `reset_gen`; `_nino_arena_destroy()` frees every slab on thread teardown.

#### 5.1.2 Allocation Ownership Inventory

- **Allocated in `NinoArena`**: `nino_str_concat` (and all `nino_auto_concat*` wrappers), `char_at` (`nino_str_char_at`), `slice` (`nino_str_slice`), `read_file` / `file_read` (`nino_read_file`), `tcp_read`, `stdin_read_line`, `stdin_read_exact`, `char_from_code`, `sha256`, `mem_dump`, `unseal` (cached copy in `s->unsealed` on `nino_sealed_t`), `nino_dict_create`, `nino_dict_set`, `_nino_auto_to_str_int`, `_nino_auto_to_str_dbl`, `sanitize`, and newly created arrays (`_nino_alloc_arr`, `_nino_make_arr`) whose lifetime stays within the active mark frame.
- **Allocated / Promoted onto System Heap (`malloc`/`calloc`/`realloc`)**: Arrays promoted by `_nino_push_impl` when growth crosses an active `arena_mark()` (`origin < marks[mark_depth - 1]`, converting `origin = -1`, `reset_gen = 0`, `mark_id = 0` and tracked by `_nino_heap_arr_live`, reclaimable via `arr_free(arr)`), sealed string enclaves (`nino_sealed_t`, virtual-page guarded buffer `page_base` or fallback `cipher`/`pad`), explicit raw allocations (`alloc_memory`, `foreign_alloc`, `alloc_parity_buffer`, `alloc_guarded_memory`), transaction undo entries (`nino_tx_checkpoint`), and LSP open-document entries (`lsp_doc_set` / `_nino_heap_dup`).
- **Reference Header Synchronization Status**: `runtime/nino_runtime.h` is emitted verbatim from `get_runtime_header()` in `compiler/ninoc.nino` (900 lines), keeping runtime type layouts, `NinoArena`, `NinoArrHdr`, `nino_sealed_t`, `nino_tx_manager_t`, sockets, SHA-256, HMAC-SHA256, flight recorder, C11 `<stdatomic.h>` threads, dynamic linker primitives, `db_*`, `pq_*`, `zk_*`, and `Z3_*` identically synchronized.

### 5.2 Transactional Memory Checkpointing (`transact` / `compensate` / `rollback`)

The compiler supports structured and nested rollback blocks using thread-local `nino_tx_manager_t _nino_tx` (`{ nino_tx_frame_t frames[32]; volatile int depth; int entry_count; int capacity; nino_tx_entry_t* entries; }`), where each `nino_tx_frame_t` stores `{ jmp_buf buf; int base_idx; }`. On MinGW-w64 targets (`_WIN32 && __MINGW32__`), `get_runtime_header()` defines `__USE_MINGW_SETJMP_NON_SEH 1` prior to `#include <setjmp.h>` so `-O3` optimizations avoid SEH `RtlUnwindEx` frame mismatches:

- `transact {` (alias `transaction {`) calls `nino_tx_push_idx()` to capture `base_idx = _nino_tx.entry_count`, increment `_nino_tx.depth` (up to 32 active frames), and establish a `setjmp(_nino_tx.frames[...].buf)` checkpoint; normal completion calls `nino_tx_commit()`, decrementing `_nino_tx.depth` and freeing undo buffers from `frames[d].base_idx` via `nino_tx_cleanup_from` while preserving any outer transaction undo log.
- Inside a function, every scalar variable assignment (`v = e`) and bounds-checked array element assignment (`arr[i] = e`) invokes `nino_tx_checkpoint(&target, sizeof(target))` when `_nino_tx.depth > 0`, copying the pre-write bytes onto the heap undo stack (`_nino_tx.entries`).
- `abort msg` / `abort(msg)` calls `nino_abort(msg)`: when `_nino_tx.depth > 0`, it pops `d = _nino_tx.depth - 1`, invokes `nino_tx_rollback()` (restoring recorded entries down to `frames[d].base_idx` in reverse LIFO order via `memcpy` and cleaning up inner buffers), updates `_nino_tx.depth = d`, and executes `longjmp(_nino_tx.frames[d].buf, 1)` into the `} compensate {` (alias `} rollback {`) branch. Outside a transaction, `nino_abort` calls `nino_panic` (`exit(1)`).

**Transactional Boundaries**: `_nino_tx` restores checkpointed scalar variable and array-slot writes; it does NOT roll back `NinoArena` allocations, heap allocations, file writes, or socket I/O.

### 5.3 Hardware CSPRNG, Sealed Memory Enclaves, `morphic mut`, and `sha256`

#### 5.3.1 Hardware OS Entropy (`_nino_entropy_u64`)

`_nino_entropy_u64(void)` (`compiler/ninoc.nino:2026`) obtains 64-bit random entropy in priority order:

1. **Windows (`_WIN32`)**: Calls `BCryptGenRandom(NULL, (PUCHAR)&val, sizeof(val), BCRYPT_USE_SYSTEM_PREFERRED_RNG)` (linked against `-lbcrypt`). Returns `val` if status is `0` and `val != 0`.
2. **POSIX (`#else`)**: Reads 8 bytes from `"/dev/urandom"` via `fopen(..., "rb")` and `fread`. Returns `val` if `8` bytes were read and `val != 0`.
3. **Deterministic/Time Fallback**: If OS CSPRNG calls fail, mixes a transient `malloc(1)` pointer address (immediately freed), `(uint64_t)time(NULL) << 32`, `(uint64_t)clock()`, and `0x9E3779B97F4A7C15ULL` through SplitMix64 finalization (`x ^= x >> 30; x *= 0xBF58476D1CE4E5B9ULL; x ^= x >> 27; x *= 0x94D049BB133111EBULL; x ^= x >> 31;`), returning `x ? x : 0x1234567890ABCDEFULL`.

#### 5.3.2 Software Guard-Paged Masking (`sealed let`, `unseal`, and `seal_destroy`)

- **String Literal Obfuscation & `sealed let v = expr`**: For string literals assigned to `sealed let`, the compiler lowers the literal into masked byte arrays (`_nino_seal_b_*`, `_nino_seal_m_*`) decoded at initialization time into `nino_seal_bytes(...)`, avoiding plaintext storage in `.rodata`. At runtime:
  - `nino_sealed_t` contains `{ void* page_base; size_t data_bytes; size_t total_bytes; uint8_t* cipher; uint8_t* pad; char* unsealed; size_t len; uint32_t head_canary; uint32_t tail_canary; bool mlocked; bool page_guarded; }`.
  - Sets `head_canary = 0xDEADC0DE` and `tail_canary = 0xFEEDFACE`, reserves virtual pages (`VirtualAlloc` on Windows, `posix_memalign` on POSIX) followed by a `PAGE_NOACCESS`/`PROT_NONE` guard page, locks pages into RAM (`VirtualLock`/`mlock` when OS limits allow), generates a nonzero CSPRNG XOR stream in `pad` / `cipher`, and sets the data page back to `PAGE_NOACCESS`/`PROT_NONE` at rest (`seal_is_locked(v)` returns `s->mlocked || s->page_guarded`).
- **`unseal(ptr)`**: Verifies `head_canary == 0xDEADC0DE && tail_canary == 0xFEEDFACE` (otherwise returning `(const char*)ptr`), temporarily transitions `page_base` to read-only (`PAGE_READONLY` / `PROT_READ`), XOR-decodes `cipher[i] ^ pad[i]` into `s->unsealed`, restores `PAGE_NOACCESS`/`PROT_NONE`, and returns `s->unsealed`.
- **`seal_destroy(ptr)`**: Clears canaries, zeroes `s->unsealed`, makes `page_base` writable to wipe via volatile byte zeroing (`_nino_secure_zero`), unlocks and releases virtual pages / heap memory, and wipes the descriptor struct itself before `free(s)`.
- **Non-String `sealed let v = expr`**: Lowers to masked scalar representation (`nino_sealed_i64_t`, `nino_seal_i64`, `unseal_i64`) or `const volatile` binding depending on declaration mode.
- **Trust Boundary**: Page guards, compile-time literal XOR obfuscation, volatile zeroing, and swap locking reduce accidental plaintext leakage, but remain software defense-in-depth rather than hardware-enforced confidential computing (SGX/TDX/SEV-SNP).

#### 5.3.3 Morphic Variables (`morphic mut`)

`transpile_line` pairs `morphic mut v = expr` with dynamic runtime masking metadata (`nino_morphic_t { int64_t cipher; int64_t mask; }` via `nino_morphic_init` / `nino_morphic_read` / `nino_morphic_write`, deriving masks from `clock()` and golden-ratio mixing). This offers lightweight runtime obfuscation rather than side-channel-hardened encryption.

#### 5.3.4 Cryptographic Hash (`sha256`) and HMAC (`hmac_sha256`)

`sha256(const char* data)` (`runtime/nino_runtime.h`) implements NIST FIPS 180-4 SHA-256 over NUL-terminated strings, formatting 64 lowercase hexadecimal characters into `nino_arena_alloc(65)` (consecutive calls on one thread do not overwrite each other's digests unless rolled back). `hmac_sha256(const char* key, const char* msg)` implements IETF RFC 2104 HMAC-SHA256, and constant-time equality verification for MAC tags and digests is provided by `_nino_ct_streq`.

#### 5.3.5 Security Scope and Threat-Model Boundaries

`nino_sealed_t` and software masking mitigate naive `.rodata` string extraction, unguarded heap scans at rest (`PAGE_NOACCESS`/`PROT_NONE`), stale plaintext after `seal_destroy()`, and accidental I/O leaks (`E0042`), while keeping clear boundaries against privileged OS attackers:

1. An OS-level attacker with debugger attach / kernel privileges (`ReadProcessMemory` / `ptrace` / root) can re-map protected pages or read unsealed buffers returned into `s->unsealed` prior to `seal_destroy()`.
2. `pad` and `cipher` occupy separate regions within `page_base`, protected by `PAGE_NOACCESS`/`PROT_NONE` between `unseal()` / `seal_destroy()` calls.
3. Hardware TEE isolation (SGX/TDX/SEV-SNP) and external key custody are outside the runtime threat model (`enclave_attest()` explicitly sets `hardware_tee="false"`).

#### 5.3.6 Embedded Post-Quantum KEM, Safe-Prime Signatures, and ZKP Research Primitives

`get_runtime_header()` emits self-contained algebraic primitives (`pq_*`, `zk_*`) intended as research building blocks rather than NIST-accredited FIPS-203/204 production cryptography:

- **`pq_generate_keypair` / `pq_encapsulate` / `pq_decapsulate` (`RLWE64_*` and `MLKEM512_*`)**: Defaults to Ring-LWE KEM over `Z_3329[X]/(X^64 + 1)` with SHA-256 shared secret derivation (`RLWE64_*`). Passing `level == 512` (or `level >= 1024`, or compiling with `--release-pqc` defining `NINO_RELEASE_PQC 1`) selects Category-1 Module-Lattice KEM (`MLKEM512_*`) over `k = 2` modules of `Z_3329[X]/(X^256 + 1)`.
- **`pq_sign` / `pq_verify` (`SP_SCHNORR_SIG`)**: Fiat-Shamir Schnorr signature over a 61-bit Sophie-Germain Safe Prime group (`p = 2q + 1 = 2305843009213691579`, `q = 1152921504606845789`, order-`q` generators `g = 4`, `h = 49`), using branchless constant-time modular arithmetic (`_nino_ct_add_mod`, `_nino_mod_mul`, `_nino_mod_pow`) compatible with both `RLWE64` and `MLKEM512` keypairs.
- **`zk_commit` / `zk_prove_condition` / `zk_verify_proof` (`PEDERSEN_GQ_`, `ZKEQ:`, `ZKR48:`)**: Homomorphic Pedersen commitments in the same order-`q` subgroup paired with Schnorr knowledge proofs (`==`) and 48-bit Cramer-Damgard-Schoenmakers (CDS) 1-out-of-2 OR-Sigma Fiat-Shamir bit-decomposition range proofs (`>`, `>=`, `<`, `<=`, `!=`).

## Clause 6: Proof-Carrying Code (PCC) Specification and Certificate ABI

### 6.1 SMT-LIB2 Translation Rules (`expr_to_smt`, `synthesize_formal_smt`)

When PCC verification is invoked (`--proof` or `ninoc prove`), `synthesize_formal_smt(source)` translates source contracts into an SMT-LIB 2.6 script (while LSP contract diagnostics in `lsp_analyze_diagnostics` invoke `smt_expr_supported` and `expr_to_smt` directly per function).

#### 6.1.1 Expression Translation (`expr_to_smt`)

`expr_to_smt(expr)` (`compiler/ninoc.nino:3301-3437`) trims whitespace, strips balanced outer parentheses, and splits recursively using `find_top_binary_op` (`782-869`), which scans outside string literals and `()` / `{}` / `[]` nesting and returns the **rightmost** matching top-level operator (skipping `<` inside `<<` or `<=`, `>` inside `>>`, `>=`, or `->`, and unary `+`/`-` prefixes immediately following start-of-string or `([ { = + - * / % < > ! & | ,`):

| Tier | Nino Operator(s) | Selection Rule | Emitted SMT-LIB2 Form |
|---|---|---|---|
| 1a | `\|\|` | Rightmost `\|\|` | `(or <l> <r>)` |
| 1b | ` or ` | Rightmost ` or ` | `(or <l> <r>)` |
| 2a | `&&` | Rightmost `&&` | `(and <l> <r>)` |
| 2b | ` and ` | Rightmost ` and ` | `(and <l> <r>)` |
| 3 | `==`, `!=` | Rightmost across `{==, !=}` | `(= <l> <r>)` / `(not (= <l> <r>))` |
| 4 | `<=`, `>=`, `<`, `>` | Rightmost across `{<=, >=, <, >}` | `(<= <l> <r>)` / `(>= <l> <r>)` / `(< <l> <r>)` / `(> <l> <r>)` |
| 5 | `+`, `-` | Rightmost across `{+, -}` | `(+ <l> <r>)` / `(- <l> <r>)` |
| 6 | `*`, `/`, `%` | Rightmost across `{*, /, %}` | `(* <l> <r>)` / `(div <l> <r>)` / `(mod <l> <r>)` |
| 7 | `not `, `!`, unary `-`, unary `+` | Prefix match at start of trimmed expression | `(not <rest>)` / `(- <rest>)` / `<expr_to_smt(rest)>` |
| Base | Atom (identifier / integer / bool) | Fallback | `<ex>` verbatim |

#### 6.1.2 AST-Based Module Synthesis and SSA Phi-Join (`compiler/smt_prover.nino`)

`synthesize_formal_smt_ex` delegates parsed AST function nodes (`NK_FN_DECL`) to the AST-driven SMT synthesizer in `compiler/smt_prover.nino`, operating chronologically per function in SSA form (`_0_*`, `_a*`, `_phi*`):

1. Parses the pre-normalized source into an `AstPool` (`ast_parse_unit_ex`), stripping `//` and `/* ... */` comments outside strings during import/line normalization.
2. Emits `(set-logic ALL)` (`--int-logic`), `(set-logic QF_BVFP)` (IEEE 754 floats), or `(set-logic QF_BV)` (default 64-bit BitVector + signed overflow guards).
3. Declares typed constants (`(_ BitVec 64)`, `(_ FloatingPoint 11 53)`, `Int`, `Bool`) with type range bounds (`smt_type_bounds_assert`) for every function parameter, supporting single-line and multi-line function/statement bodies uniformly.
4. Lowers statements recursively over AST nodes (`NK_LET_STMT`, `NK_ASSIGN`, `NK_IF_STMT`, `NK_WHILE_STMT`, `NK_FOR_RANGE`, `NK_BLOCK`, `NK_RETURN_STMT`) while tracking SSA symbol versions (`ssa_map`) and active branch path conditions (`path_stack`):
   - **`if` / `else if` / `else` path sensitivity & SSA Phi-Join**: Evaluates `then` and `else` branches under complementary path guards (`pc`, `(not pc)`), and merges mutated variables at the join point via `(declare-const v_phi ...) (assert (= v_phi (ite pc v_then v_else)))` so post-branch statements and `ensure(...)` obligations observe exact branch-joined state.
   - **`require(cond, msg)`**: Emits `<path_guards>(assert <subst(cond)>)` into the function's assertion context.
   - **`ensure(cond, msg)`**: Increments `fn_ensure_cnt`; appends `(push)\n<path_guards>(assert (not <subst(cond)>))\n(check-sat)\n(pop)\n` (or fail-closed `(assert true)` for unsupported conditions).
   - **Inductive loop verification (`invariant(cond, msg)` on `while` and `for iv in lo..hi`)**: When a loop header carries `invariant(...)` assertions, verifies 3 phases in order: (1) Base Case (`invariant` holds on entry SSA state and `iv = lo`), (2) Inductive Step (isolated `(push)...(pop)` assuming `invariant(s_k)` and loop guard, symbolically stepping loop body statements plus `iv += 1`, checking `invariant(s_{k+1})`), and (3) Post-Loop Exit Fact (assigning fresh havoc exit symbols `v_p` and asserting `invariant(v_p)` and `(not guard(v_p))`). Loops without `invariant(...)` havoc mutated loop variables (`v_h`) on exit.
5. If `total_ensures == 0`, `synthesize_formal_smt_ex` emits `; NO_VERIFICATION_OBLIGATIONS` and refuses to mint a vacuous proof. Both `--proof` and `ninoc prove` fail closed with exit code `1` unless at least one `ensure(...)` or loop `invariant(...)` obligation is verified `unsat`.

`parse_z3_verdict(z3_out)` (`compiler/smt_prover.nino`) scans every non-empty output line from Z3: if ANY line equals `"sat"`, it returns `"sat"`; else if any line is neither `"sat"` nor `"unsat"` (e.g., `"unknown"` or a solver error) or `unsat_count == 0`, it returns `"error"`; otherwise it returns `"unsat"`.

### 6.2 Z3 Discovery and Fail-Closed Build Gating

#### 6.2.1 Z3 Solver Discovery Order

Both `--proof` (`compile_nino_unit_ex`, `compiler/ninoc.nino`) and `ninoc prove` (`compiler/tooling.nino`) as well as LSP diagnostics (`lsp_run_z3_fn`, `lsp_analyze_diagnostics` in `compiler/tooling.nino`; `lsp_hover_lookup` does not invoke `find_z3_binary()`) call `find_z3_binary()` (`compiler/common.nino`), which probes relative to the working directory, `exe_dir = get_directory_of(argv(0))`, `NINO_HOME`, and `PATH`:

- **Windows (`is_host_windows() == true`)**:
  1. `tools\z3.exe`
  2. `bin\z3.exe`
  3. `<exe_dir>/tools/z3.exe`
  4. `<exe_dir>/z3.exe`
  5. `<exe_dir>/../tools/z3.exe`
  6. `<NINO_HOME>/tools/z3.exe`
  7. `z3` on system `PATH` (`z3 --version >nul 2>&1`)
- **POSIX (`is_host_windows() == false`)**:
  1. `./tools/z3`
  2. `./bin/z3`
  3. `<exe_dir>/tools/z3`
  4. `<exe_dir>/z3`
  5. `<exe_dir>/../tools/z3`
  6. `<NINO_HOME>/tools/z3`
  7. `z3` on system `PATH` (`z3 --version >/dev/null 2>&1`)

#### 6.2.2 Fail-Closed `--proof` (`QF_BV` Default) and `--int-logic` vs. `ninoc prove`

When `ninoc build <file.nino> [-o <out>] --proof [--bv|--int-logic]` (or `--proof-bv` / `--shared --proof`) is invoked, Z3 verification runs **after** `verify_syntax_balance`, `parse_program_ast`, and `run_semantic_type_check`, and **before** `emit_native_c_full` (or direct native emission), defaulting to 64-bit BitVector (`QF_BV+64bit-Overflow`) or IEEE 754 `Float64` (`QF_BVFP+64bit-IEEE754` / `QF_FP+64bit-IEEE754`) unless `--int-logic` opts into unbounded `ALL/QF_NIA+Array`:

- **Zero Verification Obligations**: If zero `ensure(...)` and zero loop `invariant(...)` contracts exist, `--proof` and `ninoc prove` fail closed with exit code `1` (no `.c` file or binary emitted).
- **Missing Z3**: Prints `[Nino PCC Error]`, deletes temporary `.pcc.smt2`, exits with code `1`. No `.c` file or binary is produced.
- **Z3 returns `sat` (`parse_z3_verdict == "sat"`)**: Indicates a counterexample violates a postcondition, inductive loop invariant, 64-bit signed overflow check (`QF_BV` default), IEEE 754 float edge case (`NaN`, `+/-Inf`, rounding/absorption, or float div-by-zero), or array bounds obligation. Prints `[Nino PCC Certification Error]` with the Z3 output and exits with code `1`.
- **Z3 returns inconclusive (`parse_z3_verdict == "error"`)**: Prints `[Nino PCC Error]` and exits with code `1`.
- **Z3 returns `unsat` (`parse_z3_verdict == "unsat"`)**: Proves zero counterexamples exist under the synthesized SMT formula. Computes `src_hash = sha256(source_text)`, `smt_hash = sha256(smt_spec)`, `inv_cnt = count("ensure(") + count("invariant(")`, `check_cnt = count("(check-sat)")`, `seal_hash = sha256("<src>:<smt>:<inv_cnt>:<logic>:<verdict>")`, `mac_tag = hmac_sha256(eff_key, "NINO_PCC_V2:<src>:<smt>:<inv_cnt>:<check_cnt>:<logic>:<verdict>")` (where `eff_key` is `NINO_PCC_HMAC_KEY` when set or `"NINO_PCC_DOMAIN_V2:" + src_hash` otherwise), and signs `mac_payload` asymmetrically with RFC 8032 Ed25519 using `NINO_PCC_ED25519_SEED` (when set, generated via `ninoc keygen`) or a build-ephemeral Ed25519 keypair, injecting the sealed PCC header (`build_pcc_c_header`) prior to C11 code generation.

### 6.3 Exact Sealed C11/Binary Certificate ABI

On Z3 `unsat` under `--proof`, `build_pcc_c_header` prepends the following C11 definitions (encoding `_NINO_PCC_SMT_SPEC[]` as a byte array to respect ISO C11 string literal length limits):

```c
#define NINO_HAS_PCC_CERTIFICATE 1
#define NINO_PCC_ED25519 1
static const char* _NINO_PCC_ED25519_PUB = "<64-hex-ed25519-public-key>";

static const char* _NINO_PCC_VERDICT = "UNSAT Verified - Zero Counterexamples in SMT Model";

```

#### 6.3.1 Runtime Self-Verification (`nino_init_args`)

Every Nino binary whose `main` invokes `nino_init_args(argc, argv)` inspects `argv[1]` for `--verify-proof` or `--proof-info`, with optional `--pubkey <64-hex>` (or `NINO_PCC_ED25519_PUB`), `--hmac-key <key>` (or `NINO_PCC_HMAC_KEY`), and `--reverify-z3`:

- **When `NINO_HAS_PCC_CERTIFICATE` is defined**: Recomputes `sha256(_NINO_PCC_SMT_SPEC)` against `_NINO_PCC_SMT_SHA`, `sha256("<src>:<smt>:<theorems>:<logic>:<verdict>")` against `_NINO_PCC_SEAL_SHA`, `hmac_sha256(key, mac_payload)` against `_NINO_PCC_MAC_TAG` via constant-time `_nino_ct_streq`, and validates `_NINO_PCC_ED25519_SIG` over `mac_payload` under `_NINO_PCC_ED25519_PUB` (requiring exact match against `--pubkey` / `NINO_PCC_ED25519_PUB` when pinned) via pure ISO C11 RFC 8032 `_nino_ed25519_verify_raw` (including canonical `S < L` scalar range check); verifies `(check-sat)` count matches `_NINO_PCC_CHECK_CNT >= 1`, rejects `NO_VERIFICATION_OBLIGATIONS` / `PCC_UNSUPPORTED_OBLIGATION`, enforces `(_ BitVec 64)` / `Float64` presence when indicated by `_NINO_PCC_LOGIC`, and if `--reverify-z3` is passed invokes local `z3` / `tools\z3.exe` to re-verify `_NINO_PCC_SMT_SPEC`. Exits with code `1` on any mismatch or prints `[✓ Embedded SMT Spec, SHA-256, HMAC-SHA256 & Ed25519 Re-Verified]` and exits `0`.
- **When `NINO_HAS_PCC_CERTIFICATE` is NOT defined**: Prints `[Nino Sovereign Binary]`, advising `--proof` compilation, and exits with status `1`.

### 6.4 Explicit PCC Modeling Modes and Remaining Boundaries

1. **Integer & IEEE 754 `Float64` Modes (`QF_BV`, `QF_BVFP`, `--int-logic`)**: Default `--proof` and `ninoc prove` emit 64-bit SMT bitvectors (`(_ BitVec 64)`) with 128-bit sign-extended (`(_ sign_extend 64)`) overflow checks across binary `+`, `-`, `*`, division-by-zero, and shift-range bounds, catching wraparound such as `INT64_MAX + 1`. Floating-point parameters (`float`, `f64`, `f32`) and IEEE 754 predicates (`is_nan`, `is_inf`, `is_finite`, `fp_abs`, `fp_sqrt`, `to_float`) lower to exact `Float64` (`(_ FloatingPoint 11 53)`) under `RNE` rounding (`(set-logic QF_BVFP)` when arrays are absent), checking float div-by-zero and catching real IEEE 754 absorption/NaN counterexamples (`x + 1.0 > x` failing for large/non-finite floats). Symbolic 64-bit `fp_sqrt` queries can still hit the bounded solver timeout (`-t:10000`) due to IEEE 754 bit-blasting complexity and fail closed (`unknown`). Passing `--int-logic` models mathematical integers (`Int` with parameter bit-width bounds).
2. **Array Theory (`(Array Int Int)` / `(_ BitVec 64)`)**: `[int]` / `[i64]` parameters (`<arr>_arr`, `<arr>_len`), array literals, `len(arr)`, `arr[i]` (`select`), and SSA writes `arr[i] = v` (`store`) are modeled natively with automatic `0 <= i < len(arr)` bounds proof obligations in contracted functions.
3. **Straight-Line Loops & User Calls**: Inductive `invariant(...)` checks apply to loops without inner conditional mutations across iterations, while arbitrary user function calls inside expressions abstract conservatively (`(assert true)` fail-closed under `ensure`).
4. **Asymmetric Ed25519 Verification vs. Domain Seals**: Domain-keyed HMAC (`_NINO_PCC_KEYED == 0`) detects accidental corruption inside `.rodata`, whereas passing `NINO_PCC_ED25519_SEED` (from `ninoc keygen`) signs builds asymmetrically so verifiers can authenticate binaries offline using only the non-secret `--pubkey <64-hex>` without holding a symmetric build secret (`NINO_PCC_HMAC_KEY` remains supported in parallel; `--reverify-z3` re-runs local Z3 on the embedded spec). OS code-signing (Authenticode/sigstore) remains complementary at the PE/ELF file container level.

#### Normative Example (PCC-Verifiable Contract)

```nino
fn safe_credit(balance: int, deposit: int) -> int {
    require(balance >= 0, "balance must be non-negative")
    require(deposit > 0, "deposit must be positive")
    let updated = balance + deposit
    ensure(updated > 0, "updated balance must be strictly positive")
    return updated
}

fn main() -> int {
    let total = safe_credit(100, 50)
    print(total)
    return 0
}
```

## Clause 7: Standard Runtime Interfaces (Native TCP Socket ABI and LSP JSON-RPC 2.0 Protocol Binding)

**Implementation Note**: Both the native cross-platform TCP socket primitives and the pure-Nino JSON-RPC 2.0 Language Server Protocol engine are implemented directly in `compiler/ninoc.nino` and `runtime/nino_runtime.h`.

### 7.1 Native TCP Socket ABI

#### 7.1.1 Builtin Signatures and Operational Semantics

The v1.2 runtime provides six native IPv4 TCP socket primitives (`compiler/runtime_hdr.nino`; `runtime/nino_runtime.h:339-482`):

| Nino Builtin Signature | Operational Semantics | Return / Error Contract |
|---|---|---|
| `tcp_listen(port: int) -> int` | Rejects `port <= 0 \|\| port > 65535`; initializes networking (`WSAStartup(MAKEWORD(2, 2), &wsa)` once on `_WIN32`, `signal(SIGPIPE, SIG_IGN)` once on POSIX); creates `AF_INET` / `SOCK_STREAM` socket; enables `SO_REUSEADDR`; binds `INADDR_ANY:port`; calls `listen(s, 128)`. | Socket descriptor `>= 0` on success; `-1` on invalid port or socket/bind/listen error. |
| `tcp_accept(server_fd: int) -> int` | Rejects `server_fd < 0`; blocks until an incoming TCP connection arrives on `server_fd` and accepts it. | Client socket descriptor `>= 0` on success; `-1` on error. |
| `tcp_read(client_fd: int, max_bytes: int) -> string` | Rejects `client_fd < 0 \|\| max_bytes <= 0`; clamps `max_bytes` to `16777216` (16 MiB); allocates `max_bytes + 1` bytes in `NinoArena`; receives via `recv()`; appends NUL terminator. | Arena-allocated string on success; `""` on EOF, invalid args, or error. |
| `tcp_write(client_fd: int, data: string) -> int` | Rejects `client_fd < 0 \|\| !data`; loops `send()` (in up to `65536`-byte chunks on `_WIN32`; retrying `EINTR` on POSIX) until `strlen(data)` bytes are transmitted or an error occurs. | Total bytes written (`>= 0`) on success; `-1` on error. |
| `tcp_close(fd: int) -> void` | No-op if `fd < 0`; otherwise closes the socket descriptor (`closesocket((SOCKET)fd)` on `_WIN32`; `close((int)fd)` on POSIX). | `void`. |
| `tcp_connect(host: string, port: int) -> int` | Rejects null/empty `host` or `port <= 0 \|\| port > 65535`; initializes networking; resolves `host` (supporting hostnames and IPv4 literals) via `getaddrinfo` (`AF_INET`, `SOCK_STREAM`); iterates results until `connect()` succeeds; frees `addrinfo`. | Client socket descriptor `>= 0` on success; `-1` on error. |

#### 7.1.2 Platform Headers and Linker Requirements

- **Windows (`_WIN32`)**: Runtime defines `WIN32_LEAN_AND_MEAN` and `_WIN32_WINNT 0x0601` and includes `<winsock2.h>`, `<ws2tcpip.h>`, `<io.h>`, and `<fcntl.h>` prior to `<windows.h>` (`compiler/runtime_hdr.nino`; `runtime/nino_runtime.h:21-33`). Both GCC and LLVM link steps append `-lm -lgdi32 -luser32 -lbcrypt -lws2_32` (`compiler/ninoc.nino`).
- **POSIX (Linux / macOS)**: Runtime defines `_POSIX_C_SOURCE 200809L` and includes `<unistd.h>`, `<sys/types.h>`, `<sys/socket.h>`, `<netinet/in.h>`, `<arpa/inet.h>`, `<netdb.h>`, `<signal.h>`, and `<errno.h>` (`compiler/runtime_hdr.nino`; `runtime/nino_runtime.h:4-8, 35-43`). Link steps use `-lm -lpthread` and SHALL NOT pass `-lgdi32`, `-luser32`, `-lbcrypt`, or `-lws2_32` (`compiler/ninoc.nino`).

### 7.2 LSP JSON-RPC 2.0 Protocol Binding (`ninoc lsp` / `nino lsp`)

#### 7.2.1 Transport and Wire Framing

1. **Invocation**: `ninoc lsp` (dispatched by `main()` to `run_lsp_server()`, `compiler/tooling.nino` / `compiler/ninoc.nino`) and `nino lsp` (when `nino` aliases `ninoc`).
2. **Binary-Safe Stdio**: On entry, `run_lsp_server()` calls `stdio_binary_mode()` (`compiler/runtime_hdr.nino` / `compiler/tooling.nino`; `runtime/nino_runtime.h:486-492`), switching `stdin` and `stdout` to `_O_BINARY` on `_WIN32` to prevent `\n` to `\r\n` translation from corrupting `Content-Length` byte counts.
3. **Strict Stdout Discipline**: The LSP server SHALL emit ZERO non-JSON-RPC text (such as startup banners or debug messages) to `stdout`. Diagnostic logs, if any, SHALL go exclusively to `stderr` (`stderr_write`).
4. **Message Framing and Memory Lifecycle**: Every message sent (`lsp_send` in `compiler/tooling.nino`) or received (`stdin_read_line`, `lsp_parse_content_length`, `stdin_read_exact`) uses HTTP-style headers followed by an exact-length UTF-8 JSON payload:
   ```text
   Content-Length: <N>\r\n\r\n<N bytes of JSON-RPC 2.0 payload>
   ```
   All responses and notifications call `fflush(stdout)` immediately after writing (`stdout_write_raw`), and `run_lsp_server()` calls `arena_reset()` after each iteration while open document buffers persist on the heap in `NinoLspDoc` (`lsp_doc_set`, `lsp_doc_get`, `lsp_doc_remove`).

#### 7.2.2 Supported JSON-RPC 2.0 Methods and Lifecycle

| Method | Kind | Normative Server Behavior (`run_lsp_server`, `compiler/ninoc.nino:5023-5139`) |
|---|---|---|
| `initialize` | Request | Responds with `result: { capabilities: { textDocumentSync: 1, hoverProvider: true }, serverInfo: { name: "ninoc-lsp", version: "1.0.0" } }`. (`textDocumentSync: 1` denotes full-document sync.) |
| `initialized` | Notification | Acknowledged cleanly with no response body. |
| `textDocument/didOpen` | Notification | Stores `{ uri, text }` in `NinoLspDoc`, runs `lsp_analyze_diagnostics` (`4439-4754`: `E0001` unclosed string, `E0002`-`E0004` delimiter mismatch/unclosed, and `PCC-SAT` via Z3 with `int`/`bool` parameter SMT sorting; `E0384`/`E0042` are enforced in `transpile_to_c_pcc` during compilation rather than emitted by `lsp_analyze_diagnostics`), and emits `textDocument/publishDiagnostics`. |

| `textDocument/didClose` | Notification | Removes `uri` from `NinoLspDoc` (`lsp_doc_remove`) and emits `textDocument/publishDiagnostics` with `diagnostics: []` for that `uri`. |

| Unknown request (with `id`) | Request | Responds with JSON-RPC error `{ "code": -32601, "message": "Method not found" }`. |

## Clause 8: Bootstrap Determinism and Self-Hosting Convergence Specification

### 8.1 Three-Stage Diverse Double-Compiling (DDC) Convergence Model

To verify that the self-hosted compiler (`compiler/ninoc.nino`) compiles deterministically without hidden compiler state or non-reproducible codegen, the toolchain defines a 3-stage bootstrap convergence protocol:

1. **Stage 1 (Seed Compilation)**: Compile the standalone C11 bootstrap seed `bootstrap/ninoc_seed.c` using a standard host C11 compiler (`gcc` or `clang`) to produce `stage1` (`ninoc`).
2. **Stage 2 (First Self-Compilation)**: Invoke `stage1 build compiler/ninoc.nino -o stage2[.exe]`.
3. **Stage 3 (Second Self-Compilation)**: Invoke `stage2 build compiler/ninoc.nino -o stage3[.exe]`.
4. **Fixed-Point Convergence Invariant**:
   ```text
   SHA-256(stage2) == SHA-256(stage3)
   ```
   Equality of the cryptographic SHA-256 digests of `stage2` and `stage3` demonstrates that the modular self-hosted compiler (`compiler/ninoc.nino` + 11 compiler modules under `compiler/`) has reached a bit-for-bit reproducible fixed point under the default GCC pipeline. (`ninoc version` reports `v1.2.5` and `"Stage-3 Fixed-Point Deterministic Convergence"`, while the operational CI invariant verifies `stage2 == stage3`.)

### 8.2 Deterministic Compilation Pipelines and Flags

#### 8.2.1 Default GCC Backend (`backend == "gcc"`)

`compile_nino_unit_ex` (`compiler/ninoc.nino`) discovers GCC via `get_system_gcc()` (`NINO_CC`, `CC`, `gcc` in `PATH`, and standard Windows MinGW/MSYS2/CLion fallbacks) and emits:

- **Release mode (default)**: `-O3 -s -fomit-frame-pointer`
- **Debug mode (`-g` / `--debug`)**: `-g3 -O0 -fno-omit-frame-pointer`
- **Sanitize mode (`--sanitize` / `-fsanitize`)**: `-g3 -fstack-protector-strong` (overrides `-g` flags when both are supplied)
- **Determinism and Standard Flags**: `-frandom-seed=42 -std=c11 -Wall -Wextra -Wno-unused-parameter -Wno-unused-variable -Wno-unused-function -Wno-unused-but-set-parameter`, plus `-Wl,--no-insert-timestamp` and `-lm -lgdi32 -luser32 -lbcrypt -lws2_32` when `is_host_windows()` is true, or `-lm -lpthread` on POSIX (`compiler/ninoc.nino`).

**DWARF `#line` Mapping**: `transpile_to_c_pcc` normalizes `\` to `/` in the filename (`norm_fname`) and emits `#line <cur_line_idx> "<norm_fname>"` (`compiler/c_codegen.nino`) before each non-empty emitted C line, enabling DWARF line tables under `-g3`. Because line numbers increment over `normalized` (post-import-expansion and post-`normalize_and_join_lines`), `#line` indices align exactly with single-file normalized sources and reflect expanded offsets when imports or multi-line joins are present.

#### 8.2.2 LLVM-Clang Backend and Direct SSA IR Emitter (`--backend=llvm` and `ninoc llvm`)

- **`--backend=llvm` / `-backend=llvm`**: Invokes `clang` (`get_system_clang()`, checking `NINO_CLANG`, `CLANG`, `clang` in `PATH`, and Windows LLVM fallbacks) to compile `.c` to `.o` (`-w -O3` in release, `-w -g -O0` in debug, `-w -g -fstack-protector-strong` in sanitize, without `-std=c11`; prepends `-target x86_64-pc-windows-gnu` and `get_clang_include_opt()` when `is_host_windows()` is true), then links the `.o` via `gcc` (`-s` or `-g`) with the platform `link_libs`.
- **`ninoc llvm <file.nino> [-o <ll>]`**: Invokes `emit_direct_llvm_ir` (`compiler/llvm_ir.nino`) directly inside the self-hosted compiler to synthesize opaque-pointer LLVM SSA IR (`.ll` with `target triple`, `%lv.<name>.<seq>` lexically scoped allocas, short-circuit `&&`/`||` basic blocks, sign-aware `for` step loops, NUL-terminated `@.str.*` constants, `!llvm.loop` vectorize hints, and runtime calls `@nino_require`, `@nino_ensure`, `@nino_print_int`, `@nino_print_str`) with zero external C preprocessor dependency. Standalone `ninoc llvm` lowers raw `[int]` indexing directly via GEP loads/stores without `NinoArrHdr` bounds or epoch wrappers; use `ninoc build --backend=llvm` or default C11 for checked `NinoArrHdr` array bounds and UAR enforcement. Any program using constructs, types (`Dict`, `struct`, `[float]`), array literals, lambdas, actors, or runtime/stdlib functions (`sha256`, `len`) outside the verified direct SSA subset fails closed (`exit 1`, `[Nino LLVM Subset Error]`) without writing partial `.ll` or invoking Clang silently.
- **Determinism Caveat**: The LLVM-Clang two-step pipeline omits `-frandom-seed=42` and `-Wl,--no-insert-timestamp`. Consequently, bit-for-bit PE/COFF determinism (`stage2 == stage3`) is guaranteed specifically by the default GCC pipeline.

#### 8.2.3 Direct Self-Hosted Machine-Code & Executable Backend (`--backend=native*` and `ninoc asm`)

`compile_nino_native_opts` and `nat_compile_ast` lower `AstPool` (post-`nir_optimize_ast`) directly into machine-code bytes and standalone container headers via `nino_write_hex_file` with **zero host `gcc`, `clang`, or `ld` invocation**:

- **Targets & Flags**:
  - `--backend=native`: Emits native host executable (`native-pe` on Windows, `native-elf` on Linux).
  - `--backend=native-pe`: Emits Windows `x86_64` PE32+ console executable (`0x200` headers, `.text` RIP-relative ISA, `.rdata` `kernel32.dll` IAT/ILT for `ExitProcess`, `GetStdHandle`, and `WriteFile`).
  - `--backend=native-elf`: Emits Linux `x86_64` ELF64 (`e_machine = 62`, `ET_EXEC`, `PT_LOAD` segments plus `.text`/`.rodata`/`.shstrtab` section headers) using direct `sys_write`/`sys_exit` syscalls.
  - `--backend=native-arm64` / `--arch=aarch64`: Emits Linux `AArch64` ELF64 (`e_machine = 183`) with `16`-byte aligned stack frames, `ADRP+ADD` literal addressing, and `svc #0` syscalls.
  - `ninoc asm <file.nino> [--arch=x86_64|aarch64] [--format=pe|elf] [-o <out.asm>]`: Emits resolved machine-code byte listings alongside instructions and `.rodata` string tables.
- **Standalone Native Subset & Fail-Closed Diagnostics**: Supports multi-function calls and recursion, `int`/`bool`/`string` stack locals and assignments, arithmetic/bitwise/comparison/short-circuit operators with runtime division-by-zero traps, `if`/`else`, `while`, `for i in a..b`, `break`/`continue`, `return`, `abort`, runtime `require`/`ensure`/`invariant` enforcement, `len(str)`, `exit(code)`, and `print(...)` (including string literal interpolation `{var}`). Programs using C-runtime heap/libc structures (floats, arrays, structs, dicts, C FFI) fail closed with `[Nino Direct Native Backend Error]` without falling back to GCC or writing `.c` output.

#### 8.2.4 NIR Loop Auto-Vectorization (`NF_VEC_SAFE`, `VEC_MAP`, `VEC_REDUCE`)

`nir_vec_analyze_for` (`compiler/nir.nino`) detects affine `0..N` loops with unit step and zero loop-carried dependencies across:
- **Element-Wise Vector Maps (`VEC_MAP`)**: Independent indexed assignments `dst[i] = expr(a[i], b[i], scalar)` over numeric arrays (`int64_t*`, `int32_t*`, `uint64_t*`, `uint32_t*`, `double*`, `float*`, `uint8_t*`) without `/`, `%`, calls, or nested control flow.
- **Modular Integer Reductions (`VEC_REDUCE`)**: Accumulations `acc = acc + term` over `int64_t`/`int32_t` targets where 4-lane modular addition preserves bit-exact equivalence (`mod 2^64`).
- **Soundness & Lowering**: Emits hoisted pre-loop bounds and epoch checks (`if (vn > 0)` verify `0` and `vn - 1`), preserves transactional isolation (`_nino_tx.depth == 0`), checks runtime non-aliasing for distinct write targets `(const void*)w != (const void*)other`, binds ISO C11 `restrict`-qualified pointers inside explicit 4-lane loops plus scalar remainder tails, annotates NIR SSA with `@nir_vec_loop`, emits LLVM `!llvm.loop` `vectorize.width=4` metadata, and reports `VecLoop=<count>` telemetry in `nir_stats_summary`.

### 8.3 Bootstrap Seed Scripts (`bootstrap/install.bat` vs. `bootstrap/install.sh`)

## Clause 9: Theorem-Driven Witness Synthesis, C-Header Bindgen, Flight Recorder, and Canonical Formatter

### 9.1 Theorem-Driven Counterexample Witness Synthesizer (`ninoc witness`)

`ninoc witness <file.nino> [-o <out.nino>]` (`synthesize_witness_nino` and `extract_z3_model_param`) extends the SMT contract prover by appending `(get-model)` after `(check-sat)` for each `ensure(...)` obligation:

1. **Counterexample Extraction (`sat`)**: When Microsoft Z3 reports `sat`, `extract_z3_model_param` parses `(define-fun <param> () <Sort> <val>)` from Z3's model output (handling negative S-expressions such as `(- 42)` and boolean literals `true`/`false`).
2. **Executable Reproduction Synthesis**: Synthesizes a standalone Nino source file (`<file>.witness.nino` or `-o <out.nino>`) containing a reproduction function `witness_check_<fn>_<idx>(...) -> bool` that records each parameter into the SHA-256 Flight Recorder (`trace_record`), evaluates the function's local bindings and `require`/`ensure` predicates on Z3's exact model inputs, and confirms at runtime that `pre_ok && (post_ok == false)`.

### 9.2 Native C-Header Bindgen Engine (`ninoc bindgen`)

`ninoc bindgen <header.h> [-o <bindings.nino>]` (`generate_c_bindgen`, `strip_c_comments`, `map_c_type_to_nino`) translates C header files directly into clean Nino FFI declarations:

- **Preprocessor Constants**: `#define NAME VALUE` constants are lowered into typed `let NAME: int = VALUE` or `let NAME: string = VALUE` bindings.
- **Composite Structures**: `struct Name { ... };` and `typedef struct ... { ... } Name;` declarations are lowered into `struct Name { ... }` blocks with C types mapped (`const char*` / `char*` -> `string`, `int64_t` / `size_t` / pointers -> `int`, `int32_t` / `uint32_t` -> `i32`, `double` / `float` -> `float`, `bool` / `_Bool` -> `bool`, `uint8_t` -> `byte`).
- **Foreign Function Prototypes**: C function declarations are lowered into `extern fn <name>(<params>) [-> <ret_type>]`.

### 9.3 Deterministic Time-Travel Flight Recorder (`ninoc trace` & `trace_*`)

Both `runtime/nino_runtime.h` and `get_runtime_header()` provide a thread-local 256-entry ring buffer (`NinoTraceEntry _nino_trace_ring[256]`) coupled with a rolling FIPS 180-4 SHA-256 state chain (`_nino_trace_hash`):

- `trace_reset()`: Resets `_nino_trace_total = 0` and initializes `_nino_trace_hash` to the 64-zero genesis string (`"0" * 64`).
- `trace_record(label: string, val: int)`: Increments step $k$, formats `"<prev_hash>:<label>:<val>"`, updates `_nino_trace_hash = sha256(msg)`, and records `(step, label, val, hash)` into `_nino_trace_ring[(k - 1) & 255]`.
- `trace_checkpoint(label: string)`: Records a named execution checkpoint with the current transition counter.
- `trace_chain_hash() -> string`: Returns the current 64-character hex SHA-256 execution state chain digest.
- `trace_count() -> int`, `trace_entry_val(idx: int) -> int`, `trace_entry_label(idx: int) -> string`, `trace_entry_hash(idx: int) -> string`: Programmatic ring-buffer inspection primitives.
- `trace_dump()`: Prints the formatted flight recorder table and terminal SHA-256 chain hash to `stdout`. Automatically invoked by `nino_require` and `nino_ensure` prior to termination if `_nino_trace_total > 0`.

### 9.4 Native Canonical Source Formatter (`ninoc fmt`)

`ninoc fmt <file.nino> [--check] [-o <out.nino>]` (`format_nino_source`) normalizes CRLF to LF, trims trailing whitespace, collapses consecutive blank lines, and enforces canonical 4-space block indentation by tracking `{` and `}` depth outside string literals (`count_braces_outside_str`). In `--check` mode, exits with `0` if the source matches canonical formatting or `1` if formatting drift is detected.

### 9.5 Native Shared Library (`--shared`) and Universal Mobile Engine (`ninoc mobile`)

- **`ninoc build <file.nino> --shared [-o <lib.dll|lib.so>] [--proof]`** (`compile_nino_shared_unit`, `generate_c_header`): Emits `#define NINO_SHARED_LIB 1` (suppressing synthetic `int main`), generates a C11 / Objective-C / Swift bridging header (`<output>.h`) with `NINO_API` (`__declspec(dllexport)` on Windows, `__attribute__((visibility("default")))` on POSIX/Android/iOS), optionally certifies all `require`/`ensure` contracts via Microsoft Z3 (`--proof`), and invokes GCC with `-shared` (plus `-fPIC` on POSIX) to produce a native dynamic library.
- **`ninoc mobile <file.nino> [--pkg <pkg>] [--class <Class>] [-o <prefix>] [--proof]`** (`build_mobile_bridges`, `generate_swift_bridge`, `generate_kotlin_bridge`, `generate_jni_c_bridge`): Dynamically parses top-level functions in `<file.nino>` and emits:
  1. `<prefix>_<stem>.h` (iOS / C11 Bridging Header),
  2. `<prefix>_module.modulemap` (Apple Clang Module Map),
  3. `<prefix>_<Class>.swift` (iOS Swift 5 native wrapper),
  4. `<prefix>_<Class>.kt` (Android Kotlin `external fun` wrapper with `System.loadLibrary`), and
  5. `<prefix>_<stem>_jni.dll` / `lib<prefix>_<stem>_jni.so` (compiled Android NDK JNI shared library exporting `Java_<pkg>_<Class>_<fn>` entrypoints).
- **Runtime Dynamic Linker Primitives**: `dylib_open(path) -> int`, `dylib_sym(handle, sym) -> int`, `dylib_call_i64(fn_ptr, a, b) -> int`, `dylib_call_str(fn_ptr, s) -> string`, `dylib_call_jni_i64(fn_ptr, a, b) -> int`, `dylib_call_jni_str(fn_ptr, s) -> string`, and `dylib_close(handle)` wrap `LoadLibraryA`/`GetProcAddress`/`FreeLibrary` on Windows and `dlopen`/`dlsym`/`dlclose` on POSIX.

### 9.6 Batteries-Included Standard Library Modules (`std/json`, `std/http`, `std/fs`, `std/str`, `std/uuid`, `std/env`)

- **`std/str.nino`**: `str_index_of`, `str_contains`, `str_starts_with`, `str_ends_with`, `str_trim`, `str_replace`, `str_to_upper`, `str_to_lower`, `str_repeat`, `str_pad_left`.
- **`std/json.nino`**: `json_escape_str`, `json_has_key`, `json_get_string`, `json_get_number`, `json_get_bool`, `json_kv_str`, `json_kv_int`, `json_kv_bool`, `json_object2`, `json_object3`.
- **`std/http.nino`**: `http_build_json_response`, `http_extract_status_code`, `http_extract_body`, `http_get`, `http_post_json`.
- **`std/fs.nino`**: `fs_read_text`, `fs_write_text`, `fs_append_text`, `fs_copy_file`, `fs_exists`, `fs_remove`, `path_normalize`, `path_join`, `path_basename`, `path_dirname`, `path_ext`.
- **`std/uuid.nino`**: `hex_encode`, `hex_decode`, `base64_encode`, `uuid_v4_from_seed`, `uuid_v4`.
- **`std/env.nino`**: `dotenv_trim_val`, `dotenv_parse_key`, `dotenv_get_from_file`.
- **`std/regex.nino`**: `regex_match`, `regex_search`, `regex_find_pos`.
- **`std/csv.nino`**: `csv_row_count`, `csv_col_count`, `csv_get_cell`, `csv_escape_cell`, `csv_build_row3`.
- **`std/jwt.nino`**: `base64url_encode`, `jwt_sign_hs256`, `jwt_verify_hs256`, `jwt_extract_payload_part`.

### 9.7 High-Density Language Primitives, Equivalence Prover (`ninoc equiv`), SBOM (`ninoc sbom`), and RFC 9669 eBPF Engine

- **Compile-Time Struct Synthesis (`synthesize_struct_methods`)**: For every non-generic `struct <Name>` composed of scalar fields (`int`, `i64`, `i32`, `u32`, `u64`, `u8`, `byte`, `float`, `f64`, `f32`, `bool`, `string`, `str`), the compiler automatically emits `static inline const char* <Name>_to_json(<Name> _s)`, `static inline <Name> <Name>_from_json(const char* _j)`, and `static inline bool <Name>_eq(<Name> _a, <Name> _b)`.
- **Expression-Level Pipe Composition (`|>`)**: In `transpile_expr`, `lhs |> fn(a, b)` is lowered to `fn(lhs, a, b)` (and `lhs |> fn()` or `lhs |> fn` to `fn(lhs)`), enabling arbitrary left-to-right expression chaining.
- **Higher-Order Inline Lambdas (`arr_map`, `arr_filter`, `arr_reduce`)**: Lowered in `transpile_expr` into C11 statement expressions (`({ ... })`) iterating over fat-pointer arrays.
- **Native OS Threading & System FFI**: `thread_spawn(fn, arg)`, `thread_join(id)`, `thread_os_id(id)`, `current_thread_id()`, and `cpu_core_count()` wrap Win32 `CreateThread` and POSIX `pthread_create` with thread-local `NinoArena` teardown; `ffi_open_system_lib` and `hmac_sha256` provide dynamic system library resolution and RFC 2104 HMAC-SHA256.
- **Native Vector and SQL-to-JSON Builtins**: `str_split`, `str_join`, `arr_sum`, `arr_min`, `arr_max`, `arr_sort`, `arr_contains`, `db_query_json`, and `time_now_ns` are emitted in `get_runtime_header()`.
- **RFC 9669 64-Bit eBPF Engine**: `ebpf_prog_create`, `ebpf_emit`, `ebpf_bytecode_hex`, and `ebpf_exec_packet` encode and execute 8-byte RFC 9669 eBPF instructions over raw packet frames with bounds checking.
- **Differential Equivalence Prover (`ninoc equiv <v1.nino> <v2.nino>`)**: Synthesizes relational SMT-LIB2 obligations asserting `(not (= ret_v1 ret_v2))` under shared preconditions and invokes Microsoft Z3 to prove equivalence (`unsat`) or extract a counterexample (`sat`).
- **CycloneDX v1.5 SBOM Generator (`ninoc sbom <file.nino> [-o <sbom.json>]`)**: Computes FIPS 180-4 SHA-256 digests of the root compilation unit and all resolved `import` modules, emitting a CycloneDX v1.5 JSON manifest.
